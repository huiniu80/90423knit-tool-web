# 编织图形转针法工具

一个将真实厘米尺寸下的几何图形离散成编织针格，并生成逐行加减针方案的纯前端工具。

## 已实现功能

- 编织小样密度和真实画布尺寸换算。
- 精简的路径、选择和平移工具。
- 使用选择工具选中图形，使用平移工具拖动整条路径，并支持缩放与精确 cm 属性编辑。
- 自定义贝塞尔路径：开放/闭合路径、端点吸附、边中点弯曲、独立控制手柄和曲线插点。
- 真实比例网格、缩放、平移、轮廓/针格/对比三种显示模式。
- Center、Inside 和 Outside 三种离散策略。
- 开放直线和弧线按经过针格生成一针格宽轨迹。
- 每个轮廓对象独立生成 Bottom-Up 或 Top-Down 逐行编织计划；轮廓标注显示方向与左右加减针规律，点击标注可切换方向并同步重算描述。
- 撤销/重做、JSON v3 导入/导出（兼容 v1/v2）和分离区域警告。

## 本地开发

```bash
npm install
npm run dev
```

## 验证

```bash
npm run test:run
npm run build
```

## Core 分层原则

所有核心业务数据使用 cm；px 只能出现在未来的 UI/渲染层。`src/core` 不得依赖 Vue、Pinia、Konva、DOM 或 Canvas。
