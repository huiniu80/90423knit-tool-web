# 编织图形转针法工具

一个将真实厘米尺寸下的几何图形离散成编织针格，并生成逐行加减针方案的纯前端工具。

## 已实现功能

- 编织小样密度和真实画布尺寸换算。
- 精简的路径、选择和平移工具。
- 使用选择工具选中图形，使用平移工具拖动整条路径，并支持缩放与精确 cm 属性编辑。
- 自定义贝塞尔路径：开放/闭合路径、端点吸附、边中点弯曲、独立控制手柄和曲线插点。
- 真实比例网格、缩放、平移、绘版/针格/量衣三种显示模式。
- 当前固定使用针格中心；旧 Inside/Outside 方案打开或导入时自动迁移、保留源轮廓并提示一次结果可能变化。
- 开放路径仅保存和编辑，闭合前不参与尺寸取整、针格、编织计划或图片导出。
- 自相交或越界织片保留源轮廓，暂停针格和编织计划，修正后恢复；三段以上或中途整行无针保留针格，但停止计划并显示原因。图片只导出有效织片。
- 当前固定自下而上，旧方向不改变计算或取整固定底边。
- 撤销/重做和分离区域警告。
- 本地方案库：最多保存 5 份完整织片方案，支持自动保存、新建、切换、重命名、删除和旧存档迁移。

## 本地开发

```bash
npm install
npm run dev -- --host localhost --port 4173 --strictPort
```

## 验证

```bash
npm run test:run
npm run build
```

## Core 分层原则

所有核心业务数据使用 cm；px 只能出现在未来的 UI/渲染层。`src/core` 不得依赖 Vue、Pinia、Konva、DOM 或 Canvas。
