# 编织图形转针法工具

一个将真实厘米尺寸下的几何图形离散成编织针格，并生成逐行加减针方案的纯前端工具。

## 已实现功能

- 编织小样密度和真实画布尺寸换算。
- 精简的路径、选择和平移工具。
- 使用选择工具选中图形，使用平移工具拖动整条路径，并支持缩放与精确 cm 属性编辑。
- 自定义贝塞尔路径：开放/闭合路径、端点吸附、边中点弯曲、独立控制手柄和曲线插点。
- 真实比例网格、缩放、平移、绘版/针格/量衣三种显示模式。
- 当前实现仍有 Center、Inside 和 Outside 三种离散策略；已确认的产品目标是固定使用 Center，后续移除另外两种用户选项。
- 当前底层仍能把开放直线和弧线生成为一针格宽轨迹；已确认的产品目标是开放路径闭合前不参与针格、编织计划或正式导出。
- 当前实现可为每个轮廓切换 Bottom-Up 或 Top-Down 计划；已确认的产品目标是当前只保留自下而上编织，自上而下工艺留待后续设计。
- 撤销/重做和分离区域警告。
- 本地方案库：最多保存 5 份完整织片方案，支持自动保存、新建、切换、重命名、删除和旧存档迁移。

## 本地开发

```bash
npm install
npm run dev
```

## 验证

```bash
npm run test:run
npm run build
```

## Core 分层原则

所有核心业务数据使用 cm；px 只能出现在未来的 UI/渲染层。`src/core` 不得依赖 Vue、Pinia、Konva、DOM 或 Canvas。
