# 编织方向与加减针方案

> 文档状态：部分确认
>
> 规则归属：逐行边界比较、方向、分片/连接识别、加减针压缩和分段说明以本文为唯一主要说明。

## 一、功能目的

面向使用编织机分别片织的后片、左前片、右前片等独立织片，把针格每一行的边界变化转换为可逐行核对的权威操作表，明确行号、左右侧和加减针数；同时归纳机织起针、平织、加针、减针、平收和中间分段摘要，不根据几何变化自动命名具体服装部位。

## 二、使用入口

- 在“绘版”模式查看所有边界段的编织卡。
- 在“针格”模式点击红色轮廓段查看该段编织卡。
- **已确认目标入口：**当前只支持自下而上，不提供方向切换。现有卡片右上角仍可在“自下而上”和“自上而下”之间切换，尚未调整。
- 工具栏在选中闭合织片时显示起针数、总行数和取整待确认状态。

## 三、用户操作流程

1. 完成闭合轮廓、密度、针格策略和必要取整。
2. 选择织片，在绘版或针格模式阅读编织卡。
3. 按自下而上的编织行号查看逐行操作表，确认每行左侧、右侧或中间需要加减的针数。
4. 用压缩摘要快速查看各边界的加减针阶段、中间分段和左右针段继续编织情况，并与逐行表核对。
5. 对照针格中的编号标记检查变化发生在哪一行、哪一侧。
6. 若出现不支持或未落入针格，返回修改轮廓、密度或取整。

## 四、当前可观察行为

- **根据现状整理且与目标规则不一致：**每个闭合轮廓独立生成计划，当前默认自下而上但允许切换，方向按对象分别保存。目标规则固定自下而上，不再保存方向选择。
- **根据现状整理：**只处理第一到最后一个有针格的物理行；前后空画布行忽略，中间空行仍进入计划并可能不支持。
- **根据现状整理：**每行最多两个针段时尝试归纳；当前行或前一行超过两个针段即标记不支持。
- **根据现状整理：**一个针段到一个针段时，分别比较左右端点，正变化记加针、负变化记减针。
- **根据现状整理且与目标规则部分不一致：**一个针段变两个针段时，当前识别为中间收针并分成左右肩；目标规则保留中间平收和左右分段，但不自动命名为领口或肩部。两个变一个时当前识别为中间加起并连接。
- **根据现状整理：**第一行有两个针段时允许“左右片分别起针”。
- **根据现状整理：**同一侧连续出现相同间隔、相同针数、相同操作时压缩为一个重复规则；顺序保持不变。
- **根据现状整理且与已确认规则不一致：**当前外侧一次减超过一针就在画布卡中称为“平收”。目标规则不跨行分散，直接按离散针格逐行比较；单侧单行减少一至三针称为减针、四针及以上称为平收，针段完全结束时全部平收。
- **根据现状整理：**任意形状的外边界使用“左侧边界塑形/右侧边界塑形”等中性名称，不自动称作袖窿。
- **根据现状整理：**显式左右镜像轮廓只用左侧代表段展示规律，并提示右侧镜像编织。
- **根据现状整理：**README 写有“分离区域警告”，状态层也能识别一行多段，但当前页面没有独立警告入口。
- **待确认：**这些几何差值是否足以成为实际可执行编织说明。

## 五、正确结果

**部分确认：**最终结果应明确告诉用户从哪里起针、按哪个方向、在哪些行对哪一侧加减多少针、何时分片或连接，并可用于实际编织。

**已确认：**主要制作场景是多个独立织片分别片织后缝合；每个闭合轮廓应拥有独立编织计划，不能从总画布并集生成一份合并计划。

**已确认：**用户主要使用编织机，一般不手工棒针编织。方案不应默认推荐三针收针等手织方法。基础形状和针行换算不依赖机型；当前逐行表使用通用表达，只说明行号、左右位置和加针、减针或平收数量，不指定移针方法、加针工具或机器专用步骤。

**已确认：**逐行操作表是权威结果，每条操作必须明确编织行号、左侧或右侧以及加减针数；压缩规律只能从逐行表派生并作为辅助摘要。两者不一致时以逐行表为准。当前页面主要展示压缩卡片，尚未满足该目标。

**已确认：**第 N 行的全部操作在编织该行之前完成；同一行有多处操作时按织片从左到右展示并视为同时生效，随后再编织第 N 行。展示顺序不改变计算结果；操作相互影响时必须警告，不自动猜测。

**已确认：**当前只处理主体平针，不跨行分散针数变化。逐行操作直接对应离散针格的相邻行差值，避免为了平滑而提前或延后操作。多个闭合轮廓当前始终是独立织片，不提供组合计划。

**已确认：**同一闭合织片从一段连续针变成左右两段时，输出“本行中间平收 N 针，之后左右两段分别继续编织”，不自动判断为领口或左右肩。

**已确认：**当前只支持自下而上编织，从最低有效物理行开始编号并固定纵向取整的底边。自上而下及其加起、连接和固定顶边规则留待未来单独设计。

**已确认：**任一行出现三段以上，或首末有效行之间出现整行无针时，当前停止生成编织计划，保留轮廓供用户修改，并明确提示“不支持的复杂断开结构”；不得自动猜测分片、断纱或重新起针。

**范围说明：**当前结果不指定正反面行、具体加减针技法或机器动作，因此只能作为平针织片的通用逐行数量计划，不能宣称已经验证特定机器的完整操作流程。机器专用能力、领口工艺和其他高级规则留待未来确认。

## 六、输入与输出

- 用户输入：来自密度、轮廓和取整；当前固定使用针格中心离散并按自下而上生成计划，方向不是用户输入。
- 系统读取：按物理高度排列的各行针段、针段首尾针号、边界段位置和可选镜像约束。
- 系统计算：编织行号、源物理行、该行针数、左右变化、中心变化、分片状态、各肩变化和压缩阶段。
- 系统输出：权威逐行操作表、由其派生的压缩摘要、工具栏摘要、边界段卡片、编号标记和导出中的编织说明。

## 七、数据保存与更新

- 当前代码保存每个对象的编织方向，但目标规则固定自下而上，不再把方向作为业务配置；逐行指令和压缩规则仍不保存。
- 密度、画布、轮廓、取整或方向变化后，指令重新生成。
- 删除或合并对象时清理对应方向；新对象当前默认自下而上。
- 当前方向切换可撤销、重做并自动保存；目标流程移除该操作。
- 卡片手工位置和展开状态不属于编织方案数据，不随方案保存。

## 八、编织与计算规则

### 当前算法行为

- 目标规则只按物理行由低到高编号，第一有效行编号为 1。当前代码仍支持自上而下反序编号。
- 行号 N 表示“先完成第 N 行的全部行前操作，再编织第 N 行”。同一行操作按物理位置从左到右列出，并在针格状态中同时生效。
- 左边变化＝前一行左端针号－当前行左端针号；右边变化＝当前行右端针号－前一行右端针号。
- 规则中的“每几行”＝本次变化行号－上一次同一边界发生变化的行号；外边界从第 0 行算起，领口侧从分片行算起。
- 同间隔、同针数、同操作的相邻阶段合并重复次数。
- 压缩阶段只能从完整逐行操作表归纳，不能反向作为权威源数据；无法安全归纳时保留逐行步骤，不强行压缩。
- 中间平收针数取两个新针段之间的空缺；连接时中间加起针数取原两个针段间空缺。当前不据此自动命名领口或肩部。
- 水平起始边显示起针；末端水平边显示平收或肩部保留和平织说明。

### 产品风险

- “每几行”没有区分正面和反面；现实中很多塑形只在特定面操作。
- 正负针数只说明数量，不说明具体移针、加针工具或机器动作；这是已确认的当前范围，不得误写成机型已验证步骤。
- 外侧一次减多针自动称为平收，未验证是否适合所有部位或方向。
- 当前没有用户覆盖自动工艺的入口；不跨行分散本身符合已确认的当前平针规则。
- 当前一段变两段仍被固定解释为左右肩/领口，与已确认的通用中间分段表达不一致。
- 当前代码的方向反转会把减针变加针并改变纵向取整固定边，但没有配套的起针和连接工艺；目标流程已移除自上而下。
- 标注按“最近服装边界”匹配轮廓段，复杂几何可能归到错误边界。
- 当前说明没有记录编织机机型、针床、可用移针/持针方式或后整理设备，几何上成立的加减针不一定能在目标机器上直接执行。

### 用户确认状态

现有测试证明计算内部一致，不证明实际编织合理；所有具体规则均未取得用户确认。

- 间接依赖[编织密度与画布尺寸](./编织密度与画布尺寸.md)和[形状绘制与轮廓编辑](./形状绘制与轮廓编辑.md)。

## 十、不同设备的操作方式

- 鼠标：在绘版查看全部卡；针格模式点击轮廓段；点击方向按钮；可拖动卡片。
- 触控：卡片按钮和拖动在触控分支前处理，理论上可用；但针格模式的轮廓触控点击当前被忽略，无法按提示选择段。
- Apple Pencil：理论上可点轮廓段和卡片控件，真实设备未验证。
- iPad 横屏：卡片在画布左右自动排列，较矮视口会压缩为一张展开、其余折叠。
- iPad 竖屏：画布更窄，卡片可能遮挡较多空间；可拖动但位置不保存。

## 十一、异常与边界情况

- 没有针格时显示“未落入针格”。
- 开放路径显示“开放路径不形成织片”。
- 三段以上显示不支持归纳；但当前页面缺少总览警告，用户可能只在特定卡中发现。
- 首末有效行之间出现整行无针时，必须停止计划；当前代码的提示和阻止范围仍需核对。
- 一行没有变化且仍有针时显示不加不减；直边尝试显示实际平织行数。
- 初始即为两段时显示两片分别起针。
- 中途出现零针空行时可能被判不支持，没有“断纱后重新起针”等正式产品语义。
- 复杂轮廓的多个段可能生成重复说明；页面会按相同过程去重，但去重口径未确认。

## 十二、必须保持不变的行为

- **已确认目标规则：**当前固定自下而上，不提供每对象方向切换；现有切换能力不得作为必须保持的产品行为。
- **根据现状整理：**左右边界分别计算，阶段顺序不被排序打乱。
- **根据现状整理：**不支持的结构不会伪装成已归纳方案。
- **根据现状整理：**镜像轮廓避免重复两套相同卡片。
- **已确认目标规则：**一段变两段使用通用的中间平收与左右分段说明；具体领口、肩部名称和专用工艺必须等未来有明确部位标记或模板规则后再使用。

## 十三、验收标准

- [ ] 当前只按自下而上的物理行顺序生成计划和标注，不提供自上而下切换。
- [ ] 一段到一段的左右加减针分别计算。
- [ ] 一段到两段时显示中间平收数量和左右两段继续编织，不自动称为领口或肩部；两段到一段、初始两段和三段以上得到不同且明确状态。
- [ ] 压缩规律保持操作顺序，间隔、针数和次数可由逐行结果复核。
- [ ] 领口、肩部、直边、末端和镜像卡片显示与针格位置一致。
- [ ] 上游变化后不保留过期指令或编号。
- [ ] 触控和 Pencil 可选择段、展开和拖动卡片；当前不需要方向切换入口。
- [ ] 实际编织专家确认前，界面或文档不把算法结果宣传为已验证针法。

## 十四、待确认问题

1. 已确认主要支持编织机上的独立织片平面片织，且机型不参与核心换算；当前采用通用加减针数量表达，待确认未来是否支持圈织及可选机器能力校验范围。
2. 已确认最终单侧单行减少一至三针默认减针、四针及以上默认平收，针段完全结束时全部平收；当前不指定加针工具或减针移针方式，仍待确认用户覆盖自动分类的入口。
3. 已确认第 N 行操作在编织该行前完成，同一行按从左到右展示并同时生效；待确认哪些机织操作会相互影响并需要阻止或警告。
4. 当前只支持主体平针；压缩规则是否必须按正面行节奏和成对对称调整？影响可执行性。花样重复留待未来花样功能设计。
