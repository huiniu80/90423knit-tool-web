# 衣片类型与袖山联动

> 文档状态：部分确认
>
> 实现状态：尚未开发；本文件记录已确认的产品方向和仍待确认的计算规则。
>
> 规则归属：衣片类型、衣片关联、袖窿与袖山匹配及自动袖山生成以本文为唯一主要说明。

## 一、功能目的

让系统理解前片、后片与袖片之间的缝合关系，根据实际袖窿生成可用于片织的袖山轮廓及逐行加减针方案，并持续检查袖山与袖窿能否合理连接。

## 二、已确认的产品方向

- 闭合轮廓可以具有明确的衣片类型和关联关系，不能只依赖用户填写的名称猜测部位。
- 袖片可以关联一个前片袖窿和一个后片袖窿。
- 系统读取前、后袖窿的缝合线长度以及袖片尺寸约束，自动生成前后两侧可分别匹配的袖山曲线。
- 袖山曲线需要转换为自下而上的逐行平收、减针计划，并校验厘米长度误差、针行误差和操作可执行性。
- 用户调整关联衣片、袖肥、袖山高度、松量或相关轮廓后，系统需要更新匹配结果；是否直接覆盖用户手工编辑的袖山仍待确认。
- 当前项目仍只支持编织机片织，不因衣片关联引入圈织。

## 三、建议用户流程

1. 用户为轮廓指定后片、左前片、右前片、袖片或普通自定义衣片等类型。
2. 用户为袖片选择需要连接的前片袖窿和后片袖窿。
3. 系统读取两段袖窿缝合线长度，并展示用于求解的袖肥、袖山高度和松量。
4. 系统生成袖山候选，分别显示前侧、后侧与目标袖窿的长度差。
5. 用户确认或调整参数，系统重新生成并给出逐行编织计划。
6. 上游轮廓或密度变化后，系统重新校验关联结果，明确提示已失配或需要重新生成。

以上流程中的自动生成与持续校验方向已经确认；默认参数、交互细节和覆盖策略仍需逐项确认。

## 四、输入与输出

### 输入

- 前片与后片的成衣外观轮廓及被指定的袖窿边界段。
- 袖片类型、左右侧、关联的前后衣片和袖窿边。
- 编织密度、边类型及缝合补偿。
- 待确认的袖肥、袖山高度、袖山松量和允许误差。

### 输出

- 自动生成的袖山连续轮廓，前后侧保持可区分。
- 袖山前侧、后侧与对应袖窿的目标长度、实际长度和差值。
- 离散后的针格及自下而上逐行平收、减针方案。
- 无法在给定尺寸、密度或工艺限制内匹配时的明确错误或警告。

## 五、计算原则

- 自动袖山是多约束匹配问题，不使用一套固定的“每几行减几针”模板代替计算。
- 连续几何阶段同时考虑前后袖窿目标长度、袖肥、袖山高度、松量和前后侧差异。
- 针格阶段按当前固定的针格中心规则离散，再依据权威逐行表生成平收与减针说明。
- 求解目标至少包括：袖山与袖窿长度差尽可能小、成衣尺寸误差可见、逐行变化符合已确认工艺，并且结果可由用户调整和复核。
- 缝合补偿与边针需要在同一口径下计算，不能把成衣外观长度和织片计算边界长度混用。

具体默认值、容差和约束优先级尚未确认，不能据此直接实现算法。

## 六、数据保存与联动

- 未来方案需要保存衣片类型、左右侧、关联对象、关联边以及用户确认的袖山参数。
- 自动生成结果属于派生数据，应由轮廓、密度和袖山参数重新计算。
- 删除或打开被关联的衣片、改变袖窿边、修改密度或改变缝合补偿时，袖山匹配状态必须失效并重新校验。
- 关联失效时不得继续把旧袖山计划显示为有效结果。

## 七、iPad、Apple Pencil 与触控要求

- 衣片类型选择、关联前后袖窿、调整参数、确认候选和查看误差必须可以通过触控或 Apple Pencil 完成。
- 袖窿边的选择不能依赖悬停、右键或键盘快捷键；被选边与配对关系需要清晰的触控反馈。
- iPad 横竖屏都必须能查看前后袖窿长度、袖山候选和错误状态，不应要求精确点击过小的边段。

## 八、异常与边界情况

- 缺少前片或后片、未指定袖窿边、袖窿为开放无效数据时，不生成袖山。
- 左右袖窿关联重复、对象被删除或关联形成循环时，阻止生成并要求重新选择。
- 给定袖肥和袖山高度无法匹配目标长度时，展示冲突参数和误差，不静默扭曲轮廓。
- 离散后若出现不支持的复杂断开结构，保留轮廓和诊断，但不输出可执行编织计划。

## 十、验收标准

- [ ] 用户能明确指定衣片类型并把一只袖片关联到对应的前、后袖窿。
- [ ] 系统分别读取前后袖窿长度，不把两侧强制当作完全相同。
- [ ] 自动袖山同时满足已确认的尺寸约束，并展示两侧长度误差。
- [ ] 袖山针格可追溯到连续轮廓，逐行计划可追溯到针格。
- [ ] 上游数据变化后旧匹配不会继续显示为有效结果。
- [ ] 无法匹配时明确说明原因，不输出伪装成可执行的方案。
- [ ] 鼠标、触控和 Apple Pencil 都能完成关联、调整、确认与复核。
