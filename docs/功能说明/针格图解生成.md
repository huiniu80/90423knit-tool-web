# 针格图解生成

> 文档状态：根据现状整理
>
> 规则归属：轮廓到针格的三种离散方式、扫描位置、裁剪、合并与开放路径轨迹以本文为唯一主要说明。

## 一、功能目的

把连续的厘米轮廓转换为整数针格，使后续系统能按行读取织片宽度、分离区域和边界变化，并生成编织说明。

## 二、使用入口

- 左侧参数栏“离散策略”选择针格中心、完全在轮廓内或轮廓有覆盖。
- 工具栏“针格”和“量衣”模式显示针格填充；“绘版”模式隐藏针格填充但计算仍存在。
- 网格超限时画布被暂停，页面要求先调整小样或画布。

## 三、用户操作流程

1. 设置密度和画布尺寸。
2. 创建或导入闭合轮廓，并处理需要的尺寸取整。
3. 选择离散策略。
4. 切换到“针格”查看轮廓覆盖的针格。
5. 点击红色轮廓段查看对应编织规律，必要时修改轮廓、取整或策略并比较结果。

## 四、当前可观察行为

- **根据现状整理：**每个闭合图形独立针格化，总画布把所有闭合图形的同一行针段取并集。
- **根据现状整理：**每一行以行的垂直中心作为轮廓扫描位置。
- **根据现状整理：**“针格中心”选取中心落在轮廓横向区间内的针格；“完全在轮廓内”要求针格横向范围完全在区间内；“轮廓有覆盖”选取与区间有覆盖的针格。
- **根据现状整理：**针格被裁剪在画布总针数和总行数内，相接或重叠的针段会合并。
- **根据现状整理：**取整确认后，系统先把图形整体边界调整到目标针数/行数对应的厘米宽高，再针格化。
- **根据现状整理：**凹形可以在同一行得到多个分离针段。
- **根据现状整理：**底层计算和测试支持开放路径按经过的针格生成一针格宽轨迹，且不受三种面积离散策略影响。
- **根据现状整理：**编辑器总针格只合并被认定为织片的闭合图形，开放路径被排除，因此其底层轨迹当前不会出现在总针格填充中。
- **待确认：**开放路径矛盾应以哪一种行为为产品标准；多个图形合并为并集是否符合实际织片含义。

## 五、正确结果

**部分确认：**针格必须尽可能忠实表达用户轮廓，同时给出可实际编织的整数边界，并能稳定支持行数和加减针推导。

**待确认：**“忠实”是优先尺寸误差最小、轮廓不超出、轮廓不缩小、左右对称，还是优先满足花样倍数，目前没有产品规则。

## 六、输入与输出

- 用户输入：离散策略，以及通过上游功能产生的密度、画布、轮廓、取整和编织方向。
- 系统读取：每行轮廓横向区间、单针宽度、单行高度和画布针行范围。
- 系统生成：每个物理行的行号、中心高度、一个或多个针段、该行总针数；同时生成每对象结果和全部闭合对象的合并结果。
- 输出传递：[编织方向与加减针方案](./编织方向与加减针方案.md)、[画布查看与图片导出](./画布查看与图片导出.md)和方案缩略信息。

## 七、数据保存与更新

- 保存离散策略，不保存针格结果；当前还有一个未暴露在界面的“对称优化”数据字段，但针格算法没有读取它来改变结果。
- 密度、画布、轮廓、取整、方向或离散策略变化后，受影响对象重新针格化，合并结果同步更新。
- 编织方向本身会在已取整纵向尺寸时改变固定边，因此可能改变物理针格位置；没有纵向取整时只影响后续行顺序。
- 单个图形变化时，当前实现复用其他图形结果；产品上仍要求合并结果与完整重算一致。

## 八、编织与计算规则

### 当前算法行为

- 行中心高度＝“从画布底部起的行序号加半行”×单行高度。
- 横向区间按所选策略换成首尾针编号，再裁剪到画布范围。
- 同行重叠或首尾相接的针段合并；总针数为各针段包含的整数针数之和。
- 开放路径先按单针、单行坐标裁剪，再沿折线或细分曲线采样经过的格子；路径宽度固定为一格。
- 闭合曲线先细分成近似多边形，再用水平扫描区间针格化。

### 产品风险

- 当前“完全在轮廓内”和“轮廓有覆盖”只依据扫描行中心处的横向区间，并没有检查完整二维针格是否完全位于或部分覆盖轮廓，名称可能比算法含义更强。
- 曲线细分和开放路径采样是近似算法，极端密度、尖角或高曲率处可能漏格或多格。
- 多闭合对象直接取并集会把相接对象当成连续织片，但每对象计划仍独立，两种视角可能矛盾。
- 没有花样、颜色、针法符号、边针或接缝信息；当前“针格图解”只是占用格，不是完整针法图。

### 用户确认状态

三种策略、默认“针格中心”和所有近似规则均未经过实际编织确认。

## 九、与其他功能的关系

- 依赖[编织密度与画布尺寸](./编织密度与画布尺寸.md)的格子尺寸和安全上限。
- 依赖[形状绘制与轮廓编辑](./形状绘制与轮廓编辑.md)的闭合轮廓或开放路径。
- 依赖[尺寸换算与取整确认](./尺寸换算与取整确认.md)提供整体目标针行数。
- 直接决定[编织方向与加减针方案](./编织方向与加减针方案.md)的每行输入。
- 在[画布查看与图片导出](./画布查看与图片导出.md)中呈现和导出。
- 针格变化必须保持原轮廓厘米数据不变，并让所有逐行说明同步失效重算。

## 十、不同设备的操作方式

- 鼠标：在参数栏下拉框选择策略，在针格模式点击红色轮廓段。
- 触控：下拉框可用；但画布触控点击当前被忽略，无法按页面提示点选轮廓段查看规律。
- Apple Pencil：代码允许笔指针点击轮廓，真实命中和手掌干扰未验证。
- iPad 横屏：针格可见，工具栏可横向滚动；高密度细格在当前缩放下可能难以辨认。
- iPad 竖屏：画布可用宽度较小，轮廓段点选和细格检查风险更高。

## 十一、异常与边界情况

- 没有闭合图形时总针格为空，但仍显示完整画布网格。
- 图形完全在画布外时不生成针格，原轮廓数据不变。
- 图形部分越界时仅保留画布内针格。
- 凹形或多个对象可能在一行形成多个针段；三段以上会让后续加减针归纳不支持。
- 网格超限时针格化暂停，旧方案数据保留。
- 极窄轮廓可能因策略不同得到零针或多一针。
- 开放路径的底层轨迹与页面显示矛盾，不能把任一方当作已确认标准。

## 十二、必须保持不变的行为

- **根据现状整理：**针格以整数针和行表达，所有结果裁剪在画布内。
- **根据现状整理：**重叠针格不重复计数，每对象结果仍可独立计算。
- **根据现状整理：**上游有效变化会同步重算针格和加减针。
- **根据现状整理：**图形源数据不因针格化而被永久改写。
- 开放路径是否保持当前排除行为不能在产品确认前列为必须不变。

## 十三、验收标准

- [ ] 三种策略的首尾针计算符合本文当前算法并能产生可见差异。
- [ ] 每行使用行中心，边界针格正确裁剪和合并。
- [ ] 闭合直线、曲线、凹形和多对象结果与各自测试一致。
- [ ] 取整选择改变目标宽高时，针格行列数和固定边同步变化。
- [ ] 三段以上不会进入“已支持”的加减针结果。
- [ ] 修改单个对象后，总并集与全部重新计算结果一致。
- [ ] 触控和 Pencil 都能选择离散策略并检查目标轮廓段。
- [ ] 开放路径按未来确认的产品决定统一底层、页面、README 和测试。

## 十四、待确认问题

1. 三种策略的真实业务用途分别是什么，默认策略应如何选择？影响所有轮廓边界和加减针。
2. “完全在轮廓内”和“轮廓有覆盖”是否应检查完整二维格子，而不是只看行中心横截面？影响算法准确性和命名。
3. 多个闭合图形应合并为一张织片图解还是始终独立？是否需要用户指定组合关系？影响总针格和编织计划。
4. 开放路径是否应该显示一格宽轨迹、只作辅助线，或在闭合前完全不参与图解？影响页面、测试和导出。
5. 针格是否需要中心对称、花样倍数、边针和最小连续宽度约束？影响实际可编织性。
6. 针格与目标厘米存在偏差时，优先保外轮廓、保内轮廓还是最小误差？影响离散策略和用户预期。
