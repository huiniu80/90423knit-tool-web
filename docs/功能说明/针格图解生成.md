# 针格图解生成

> 文档状态：部分确认
>
> 规则归属：轮廓到针格的针格中心离散、扫描位置、裁剪、合并与开放路径处理以本文为唯一主要说明。

## 一、功能目的

把连续的厘米轮廓转换为整数针格，使后续系统能按行读取织片宽度、分离区域和边界变化，并生成编织说明。

## 二、使用入口

- **已确认目标入口：**当前不提供离散策略选择，固定使用针格中心规则。现有左侧参数栏仍显示针格中心、完全在轮廓内和轮廓有覆盖，尚未调整。
- 工具栏“针格”和“量衣”模式显示针格填充；“绘版”模式隐藏针格填充但计算仍存在。
- 网格超限时画布被暂停，页面要求先调整小样或画布。

## 三、用户操作流程

1. 设置密度和画布尺寸。
2. 创建或导入闭合轮廓，并处理需要的尺寸取整。
3. 切换到“针格”查看按固定针格中心规则生成的针格。
4. 点击红色轮廓段查看对应编织规律，必要时修改轮廓或取整并比较结果。

## 四、当前可观察行为

- **根据现状整理：**每个闭合图形独立针格化，总画布把所有闭合图形的同一行针段取并集。
- **根据现状整理：**每一行以行的垂直中心作为轮廓扫描位置。
- **根据现状整理且与目标规则不一致：**当前“针格中心”选取中心落在轮廓横向区间内的针格；“完全在轮廓内”要求针格横向范围完全在区间内；“轮廓有覆盖”选取与区间有覆盖的针格。页面仍允许用户切换三种策略。
- **已确认目标规则：**当前主体平针固定使用针格中心，不向用户提供另外两种策略。
- **根据现状整理：**针格被裁剪在画布总针数和总行数内，相接或重叠的针段会合并。
- **根据现状整理：**取整确认后，系统先把图形整体边界调整到目标针数/行数对应的厘米宽高，再针格化。
- **已确认但尚未实现：**小数针行数应先采用厘米误差最小的最近整数，除非用户覆盖或未来的编织约束改变推荐，再以最终整数针行数针格化。
- **已确认但尚未实现：**针格化前应在侧缝、袖缝和袖窿等常规缝合边为每片增加一针边针；平收后手工缝合的肩边每片默认增加一行并允许用户改为零行；领口、下摆和袖口等开放边不增加。补偿计入织片针行数，但不计入成衣外观尺寸。
- **根据现状整理：**凹形可以在同一行得到多个分离针段；已确认一段变两段时只向下游表达中间空缺和平收数量，不自动命名为领口或肩部。
- **根据现状整理且与目标规则不一致：**底层计算和测试支持开放路径按经过的针格生成一针格宽轨迹，且不受三种面积离散策略影响。
- **已确认目标规则：**开放路径是未闭合轮廓，闭合前不生成针格或编织计划。编辑器总针格当前只合并闭合图形，符合这一方向；底层轨迹和相关测试仍需统一。
- **已确认：**当前每个闭合图形始终表示一片独立织片，不提供多个轮廓组合；必须独立命名、选择、生成针格和编织计划。总画布并集只能作为多织片视觉总览，轮廓相接或重叠也不能合并业务结果。

## 五、正确结果

**部分确认：**针格必须尽可能忠实表达用户轮廓，同时给出可实际编织的整数边界，并能稳定支持行数和加减针推导。

**已确认：**当前主体平针优先满足明确启用的左右对称和缝合补偿，再选择厘米误差最小的针行数，并固定使用针格中心规则生成各行针格。花样与罗纹当前不实现，未来增加时先满足用户选定的花样或罗纹倍数及对称要求，再选择厘米误差最小者，边针不计入花样循环。

## 六、输入与输出

- 用户输入：通过上游功能产生的密度、画布、轮廓、取整和编织方向；当前离散规则固定，不是用户输入。
- 系统读取：每行轮廓横向区间、单针宽度、单行高度和画布针行范围。
- 系统生成：每个物理行的行号、中心高度、一个或多个针段、该行总针数；同时生成每对象结果和全部闭合对象的合并结果。
- 输出传递：[编织方向与加减针方案](./编织方向与加减针方案.md)、[画布查看与图片导出](./画布查看与图片导出.md)和方案缩略信息。

## 七、数据保存与更新

- 当前代码仍保存离散策略，但目标规则已固定为针格中心；实现时需要确定旧方案中其他策略值的迁移方式。针格结果仍不保存；当前还有一个未暴露在界面的“对称优化”数据字段，但针格算法没有读取它来改变结果。
- 已确认对称派生针格只能用于明确启用左右镜像的对象，围绕既有中心轴生成；原始轮廓、图形位置和中心轴保持不变。当前算法尚未实现。
- 普通镜像织片的派生针格必须使用偶数总针数，中心位于两针之间，并在整个织片保持同一奇偶性；左右边界变化应成对发生。中心针模式不进入当前主流程。
- 密度、画布、轮廓或取整变化后，受影响对象重新针格化，合并结果同步更新。
- 当前固定自下而上，纵向取整固定底边。现有代码中的方向切换可能改变物理针格位置，属于待移除行为。
- 单个图形变化时，当前实现复用其他图形结果；产品上仍要求合并结果与完整重算一致。

## 八、编织与计算规则

### 当前算法行为

- 行中心高度＝“从画布底部起的行序号加半行”×单行高度。
- 横向区间按针格中心是否落入范围换成首尾针编号，再裁剪到画布范围。
- 同行重叠或首尾相接的针段合并；总针数为各针段包含的整数针数之和。
- 底层现状仍会把开放路径按单针、单行坐标裁剪并采样为一格宽轨迹；该结果不是已确认产品行为，不得进入针格或编织输出。
- 闭合曲线先细分成近似多边形，再用水平扫描区间针格化。

### 产品风险

- 当前代码中的“完全在轮廓内”和“轮廓有覆盖”只依据扫描行中心处的横向区间，并没有检查完整二维针格；两者不再属于当前目标产品入口。
- 曲线细分和开放路径采样是近似算法，极端密度、尖角或高曲率处可能漏格或多格。
- 多闭合对象直接取并集会让相接对象在总览中看似连续；已确认它们默认仍是独立织片，因此界面必须避免把总并集误解为单片编织结果。
- 当前阶段只支持主体平针，不包含花样、颜色或针法符号；边针与肩缝补偿规则已确认但尚未实现，因此当前“针格图解”仍只是占用格，不是完整针法图。
- 当前整个方案只读取一套主体平针密度；后续罗纹或花纹分区需要各自密度，并正确处理跨区针行数衔接。
- 已确认当前不跨行分散针数变化，逐行操作严格读取离散后每行针数；这与当前针格算法逐行直接离散轮廓的方向一致。

### 用户确认状态

常规缝合边增加一针边针的规则已经确认但尚未实现；当前固定使用针格中心离散，不再提供三种策略选择。行中心扫描与曲线近似仍未经过实际编织样片验证。

## 九、与其他功能的关系

- 依赖[编织密度与画布尺寸](./编织密度与画布尺寸.md)的格子尺寸和安全上限。
- 依赖[形状绘制与轮廓编辑](./形状绘制与轮廓编辑.md)的闭合轮廓或开放路径。
- 依赖[尺寸换算与取整确认](./尺寸换算与取整确认.md)提供整体目标针行数。
- 直接决定[编织方向与加减针方案](./编织方向与加减针方案.md)的每行输入。
- 在[画布查看与图片导出](./画布查看与图片导出.md)中呈现和导出。
- 针格变化必须保持原轮廓厘米数据不变，并让所有逐行说明同步失效重算。

## 十、不同设备的操作方式

- 鼠标：当前代码仍可在参数栏下拉框选择策略；目标流程只需在针格模式点击红色轮廓段。
- 触控：当前策略下拉框可用但目标流程将移除；画布触控点击当前被忽略，无法按页面提示点选轮廓段查看规律。
- Apple Pencil：代码允许笔指针点击轮廓，真实命中和手掌干扰未验证。
- iPad 横屏：针格可见，工具栏可横向滚动；高密度细格在当前缩放下可能难以辨认。
- iPad 竖屏：画布可用宽度较小，轮廓段点选和细格检查风险更高。

## 十一、异常与边界情况

- 没有闭合图形时总针格为空，但仍显示完整画布网格。
- 图形完全在画布外时不生成针格，原轮廓数据不变。
- 图形部分越界时仅保留画布内针格。
- 凹形或多个对象可能在一行形成多个针段；三段以上会让后续加减针归纳不支持。
- 网格超限时针格化暂停，旧方案数据保留。
- 极窄轮廓可能因策略不同得到零针或多一针。
- 开放路径的底层一格宽轨迹与已确认产品规则不一致；在统一底层与测试前，页面不得让该轨迹进入编织结果。

## 十二、必须保持不变的行为

- **根据现状整理：**针格以整数针和行表达，所有结果裁剪在画布内。
- **根据现状整理：**重叠针格不重复计数，每对象结果仍可独立计算。
- **根据现状整理：**上游有效变化会同步重算针格和加减针。
- **根据现状整理：**图形源数据不因针格化而被永久改写。
- **已确认目标规则：**开放路径闭合前不参与尺寸取整、针格、编织计划或正式导出。

## 十三、验收标准

- [ ] 当前只使用针格中心规则，界面不提供“完全在轮廓内”和“轮廓有覆盖”选项。
- [ ] 每行使用行中心，边界针格正确裁剪和合并。
- [ ] 闭合直线、曲线、凹形和多对象结果与各自测试一致。
- [ ] 取整选择改变目标宽高时，针格行列数和固定边同步变化。
- [ ] 三段以上不会进入“已支持”的加减针结果。
- [ ] 修改单个对象后，总并集与全部重新计算结果一致。
- [ ] 触控和 Pencil 无需选择离散策略，并都能检查目标轮廓段。
- [ ] 开放路径按未来确认的产品决定统一底层、页面、README 和测试。

## 十四、待确认问题

1. 当前主体平针按已确认规则处理对称、缝合补偿和厘米误差；中心针模式、花样倍数和最小连续宽度约束留待未来需求另行设计。
2. 旧方案保存了“完全在轮廓内”或“轮廓有覆盖”时，应自动迁移为针格中心还是在打开时提示用户？影响旧方案结果变化的可理解性。
