# 画布查看与图片导出

> 文档状态：部分确认
>
> 规则归属：画布导航、三种显示模式、标注交互和 PNG 图片导出以本文为唯一主要说明。

## 一、功能目的

让用户在同一画布中比较厘米轮廓、针格和编织说明，定位尺寸或塑形问题；以 PNG 快速查看和分享当前视图，并以可打印 PDF 交付包含完整编织依据的正式文件。

## 二、使用入口

画布上方工具栏包含参数栏开关、选择、平移、路径、撤销、重做、删除、绘版/针格/量衣、缩放、适应和导出图片。

## 三、用户操作流程

1. 用“选择”查看和编辑对象，或用“平移”移动画布和整条图形。
2. 使用加减号、适应、组合键滚轮或双指手势调整视口。
3. 切换“绘版”“针格”“量衣”，分别检查编织卡、针格和尺寸卡。
4. 展开、拖动或恢复编织卡位置；当前编织计划固定自下而上。
5. 需要快速查看或分享时导出当前模式 PNG；需要实际编织或归档时导出正式 PDF。

## 四、当前可观察行为

- **根据现状整理：**画布原点说明为左下角，屏幕坐标会转换为厘米坐标。
- **根据现状整理：**“绘版”显示轮廓、网格和所有边界段编织卡，不显示针格填充。
- **根据现状整理：**“针格”显示轮廓、针格填充和网格；进入时不显示编织卡，点中一个轮廓段后只显示该段卡。
- **根据现状整理：**“量衣”显示轮廓、针格填充、网格和尺寸换算卡，不显示加减针卡。
- **已确认：**选择工具点击画布空白会取消选择并开始平移；点击图形只选择，不立即移动。平移工具按落点分工：拖空白移动视口，拖图形则选择并移动该图形；双指在任何工具下始终平移和缩放视口，不修改图形。
- **根据现状整理并已确认目标含义：**缩放范围为当前内部比例 5～60，工具栏显示为内部值乘五后的百分比；100% 只代表应用内固定的标准查看倍率，必须标注“仅视图缩放”，不表示屏幕上的真实厘米或打印 1:1。
- **根据现状整理：**组合键滚轮以指针位置为中心缩放；双指触控同时缩放和平移；加减号每次改变固定内部步长；适应最高内部比例为 48。
- **根据现状整理：**三种模式预留相同两侧标注空间，切换模式不改变画布位置。
- **根据现状整理且与目标规则部分不一致：**编织卡在较小视口自动折叠，默认展开第一张；卡片可拖动、恢复自动位置、切换方向，手工位置当前不保存。目标规则固定自下而上并移除方向切换；已确认手工位置应按画布相对位置随当前方案保存，未手工移动的卡片继续自动布局。
- **根据现状整理：**编号标记会避让卡片、其他标记、轮廓线和画布边缘。
- **已确认：**PNG 使用当前“绘版 / 针格 / 量衣”显示模式及该模式的固定图层，不提供额外图层勾选弹窗；导出时自动展开该模式需要的卡片、扩展画布容纳完整内容、填充浅色背景，并以“编织图解-日期时间”命名。
- **已确认但尚未实现：**正式编织交付物为可打印 PDF，至少包含密度、成衣外观尺寸与加入缝合消耗后的织片尺寸、针格图、权威逐行操作表和全部有效警告；PNG 只用于快速查看和分享，不作为唯一正式编织依据。
- **已确认当前阶段保持现状：**暂不修改“绘版、针格、量衣”三个名称及各模式现有图层内容，后续结合正式交付物再评估。绘版继续显示轮廓、网格和全部编织卡；针格继续显示轮廓、针格和点选段卡；量衣继续显示轮廓、针格和尺寸卡。

## 五、正确结果

**部分确认：**用户应能看清轮廓、针格、尺寸误差和编织步骤之间的对应关系；导出结果应完整、易读且不改变编辑状态。

**已确认：**画布可以同时显示全部闭合织片，但每片必须保持独立命名、选择、计算和编织计划；相接或重叠只属于视觉总览，不表示已经组合成一片织片。

**已确认：**开放路径可在编辑画布中显示以便继续编辑，但闭合前不进入正式图解导出。

**已确认：**自相交闭合轮廓可在编辑画布中显示并保存，但修正前不进入正式图解导出。

**已确认：**闭合织片部分或全部超出画布时可继续显示、保存和编辑，但在完整移回或扩大画布前不进入正式图解导出。

**已确认：**缩放百分比只控制屏幕视图。100% 表示应用内固定的标准查看倍率，不承诺物理尺寸，也不改变轮廓厘米、密度、针数、行数、计算结果或导出内容；界面需要明确提示“仅视图缩放”。

**已确认：**可打印 PDF 是当前正式编织交付物，必须包含足以独立核对和执行的密度、两类尺寸、针格图、权威逐行操作表及警告。PNG 是当前视图的快速分享图，`.knitplan` 是继续编辑所需的源文件；矢量图、CSV 和机器可读取文件不进入当前版本，留待专业版。

**已确认：**PNG 直接按用户当前所在的查看模式导出固定内容，不再要求选择图层；“绘版”包含编织卡，“针格”包含针格，“量衣”包含尺寸卡。系统自动展开并容纳该模式的完整内容，避免导出结果只包含屏幕当前可见区域。

**已确认：**用户手工拖动后的编织卡位置需要随当前方案保存，并以画布为基准记录；重新打开方案或切换设备、横竖屏后，超出当前可见范围的位置自动限制到可见区域。没有手工移动记录的卡片继续使用自动布局；本决定不要求保存卡片展开状态。

**待确认：**正式图解是否需要行号、针号、图例、分页、打印尺寸、矢量格式或结构化逐行文件；当前 PNG 只是一张当前视图图片。

## 六、输入与输出

- 用户输入：当前工具、显示模式、缩放、平移、卡片展开/位置和导出操作；当前编织方向固定为自下而上。
- 系统读取：画布尺寸、轮廓、针格、尺寸标签、编织卡和视口大小。
- 系统生成：屏幕视图、自动布局标注、连接线、编号、快速分享 PNG 和正式可打印 PDF；`.knitplan` 源文件由[方案保存与文件交换](./方案保存与文件交换.md)负责。
- 自下而上的计划来自[编织方向与加减针方案](./编织方向与加减针方案.md)；导出不修改业务数据。

## 七、数据保存与更新

- 显示模式随方案保存；参数栏展开状态单独保存在当前浏览器。
- 缩放、平移、当前工具和卡片展开状态不保存；**已确认但尚未实现：**手工卡片位置按画布相对位置随方案保存。卡片位置是否进入撤销历史仍待单独确认。
- 画布尺寸变化或侧栏开合后会重新适应或限制视口。
- 轮廓、针格、尺寸或编织规则变化后，显示内容和标注实时更新。
- 图片导出临时改变导出画布尺寸、缩放和位置，完成或失败后恢复屏幕状态。

## 八、编织与计算规则

- 本功能不定义密度、取整、针格或加减针算法，只展示其结果；分别引用[编织密度与画布尺寸](./编织密度与画布尺寸.md)、[尺寸换算与取整确认](./尺寸换算与取整确认.md)、[针格图解生成](./针格图解生成.md)和[编织方向与加减针方案](./编织方向与加减针方案.md)。
- 当前编织说明只展示通用的行号、左右位置及加针、减针或平收数量，不应在图片中暗示已经提供特定机器的完整操作步骤。
- 编织卡和导出中的压缩摘要只归纳逐行表中的真实操作，不为正面行节奏或左右成对而移动行号；只有同一行、同针数、同工艺的左右操作才合并显示。
- 一段变两段时只展示中间平收和左右两段继续编织，不应仅凭几何变化在画布或导出中标成领口或肩部。
- 三段以上或中间整行无针时，画布可继续显示轮廓和针格，但不得展示或导出一份看似可执行的编织计划，必须显示不支持状态。
- 同一行发生重复占针、操作数量超过针段或作用区域重叠时，画布标出具体行和原因；该织片的编织方案不得作为有效结果展示或正式导出。
- 导出布局当前以扩展标注后所需高度决定画布大小，并对特别高的输出降低位图密度以控制尺寸。
- 产品风险：视觉避让成功不代表标注所述编织规则正确；高密度网格在缩小后可能不可读；PNG 也没有实际打印比例保证。

## 十、不同设备的操作方式

- 鼠标：拖动画布或图形；组合键滚轮缩放；点击模式、缩放、卡片和导出按钮。
- 触控：单指在画布上始终平移，双指缩放和平移；卡片控件可点按和拖动。针格轮廓选择因触控点击被忽略而不可用。
- Apple Pencil：理论上可使用选择、绘制、图形拖动和卡片控件；真实设备未验证。
- **已确认目标规则：**选择或路径工具下单指触控操作内容；平移工具下单指或 Apple Pencil 拖图形移动图形、拖空白移动视口。双指在任何工具下始终平移缩放视口，不修改图形；Apple Pencil 执行当前工具。当前触控实现尚未完全符合。
- iPad 横屏：1024×768 无整页横向溢出；侧栏宽 250 像素，工具栏宽度不足时横向滚动，后部控件不一定立即可见。
- iPad 竖屏：768×1024 仍使用左右栏；工作区约 518 像素宽，工具栏内容约 1,022 像素宽，需要明显横向滚动。
- 风险：缩放按钮约 27×28 像素、画布手柄和部分卡片控制较小，不一定满足舒适触控目标。

## 十一、异常与边界情况

- 画布很大或视口很小时，适应比例不会低于内部值 5，内容可能不能一次完整放入。
- 平移被限制以保持画布和两侧标注区域可触达，但狭窄竖屏可能仍拥挤。
- 多张高卡片可能超出屏幕高度；自动布局会尝试移动，较小视口则折叠。
- 恢复的手工卡片位置在当前视口外时，自动限制到可见区域；不得因为设备尺寸或横竖屏变化让卡片永久不可触达。
- 导出画布上下文创建失败时不下载，屏幕状态仍应恢复；页面没有错误提示。
- PNG 下载可能被浏览器策略阻止，页面没有成功/失败状态。
- 切换到针格模式会清除之前选中的段。
- 工具栏横向滚动没有文字提示，用户可能发现不了后部按钮。
- 自相交轮廓必须明确标错并排除在正式图解导出之外；当前代码尚未完整实现该校验。
- 越界闭合织片必须明确标记为超出计算范围，不得把画布内裁剪部分导出为完整织片。

## 十二、必须保持不变的行为

- **根据现状整理：**三种模式使用同一画布位置和缩放基准。
- **根据现状整理：**图片导出不永久修改屏幕视口或业务数据。
- **根据现状整理：**标记避让后仍用连接线保留真实针位锚点。
- **根据现状整理：**所有关键工具有可见按钮，不以快捷键作为唯一入口；节点级操作例外已记录为风险。
- **已确认当前阶段保持现状：**“绘版、针格、量衣”的名称和现有图层内容暂不调整；这不是长期不可改变的专业术语标准，后续结合正式交付物可重新评估。
- 多织片总览不得把相接或重叠的轮廓标成一个合并织片，也不得从总并集生成一份编织计划。

## 十三、验收标准

- [ ] 三种模式显示的层次和卡片符合本文现状且切换不跳动画布。
- [ ] 鼠标、触控和 Pencil 的平移缩放不会误改轮廓。
- [ ] 100% 明确标注为仅视图缩放，不被解释为屏幕实物比例或打印 1:1；任意缩放都不改变业务尺寸、针行数或导出计算。
- [ ] 选择或路径工具下单指操作内容；平移工具下单指或 Pencil 拖图形移动图形、拖空白移动视口；双指始终平移缩放且不修改图形。
- [ ] 选择、取消选择、移动图形和移动视口的手势意图清楚。
- [ ] 标注在常见和密集场景中可读、可追溯到正确边界。
- [ ] 手工移动的编织卡按画布相对位置随方案恢复；换设备或横竖屏后超出范围的卡片回到可见区域，未手工移动的卡片保持自动布局。
- [ ] PNG 包含当前模式所需内容、完整标注和背景，导出后恢复编辑视图。
- [ ] PNG 不弹出图层选择，按当前查看模式导出对应固定图层，并自动展开、容纳完整内容而非只截取当前视口。
- [ ] 正式 PDF 包含密度、成衣外观尺寸、织片计算尺寸、针格图、权威逐行操作表和有效警告，可脱离编辑页面打印和核对。
- [ ] PNG 明确作为快速查看与分享文件，`.knitplan` 明确作为可编辑源文件；当前不提供矢量、CSV 或机器可读取导出。
- [ ] 编织卡及导出中的压缩摘要与逐行表行号一致，只合并完全相同的左右成对操作。
- [ ] 自相交轮廓可留在编辑画布，但修正前不进入正式图解导出。
- [ ] 部分或全部越界的闭合织片可继续编辑，但不进入正式图解导出；移回或扩大画布后恢复。
- [ ] 逐行操作存在硬冲突时标出具体行和原因，受影响织片的有效方案及正式导出保持暂停。
- [ ] 1024×768 与 768×1024 下全部工具可触达，不产生整页横向溢出。
- [ ] 真实 iPad 上双指缩放、Pencil 和手掌组合操作无冲突。
- [ ] 浏览器控制台在查看和导出过程中无错误。
