# 画布查看与图片导出

> 文档状态：根据现状整理
>
> 规则归属：画布导航、三种显示模式、标注交互和 PNG 图片导出以本文为唯一主要说明。

## 一、功能目的

让用户在同一画布中比较厘米轮廓、针格和编织说明，定位尺寸或塑形问题，并把当前视图导出为便于查看和沟通的图片。

## 二、使用入口

画布上方工具栏包含参数栏开关、选择、平移、路径、撤销、重做、删除、绘版/针格/量衣、缩放、适应和导出图片。

## 三、用户操作流程

1. 用“选择”查看和编辑对象，或用“平移”移动画布和整条图形。
2. 使用加减号、适应、组合键滚轮或双指手势调整视口。
3. 切换“绘版”“针格”“量衣”，分别检查编织卡、针格和尺寸卡。
4. 展开、拖动或恢复编织卡位置；点击方向按钮比较不同编织方向。
5. 确认当前模式和标注后点击“导出图片”，下载 PNG。

## 四、当前可观察行为

- **根据现状整理：**画布原点说明为左下角，屏幕坐标会转换为厘米坐标。
- **根据现状整理：**“绘版”显示轮廓、网格和所有边界段编织卡，不显示针格填充。
- **根据现状整理：**“针格”显示轮廓、针格填充和网格；进入时不显示编织卡，点中一个轮廓段后只显示该段卡。
- **根据现状整理：**“量衣”显示轮廓、针格填充、网格和尺寸换算卡，不显示加减针卡。
- **根据现状整理：**选择工具点击画布空白会取消选择并开始平移；点击图形只选择，不立即移动。平移工具拖空白移动视口，拖图形则选择并移动图形。
- **根据现状整理：**缩放范围为当前内部比例 5～60；工具栏显示为内部值乘五后的百分比，百分比基准未说明。
- **根据现状整理：**组合键滚轮以指针位置为中心缩放；双指触控同时缩放和平移；加减号每次改变固定内部步长；适应最高内部比例为 48。
- **根据现状整理：**三种模式预留相同两侧标注空间，切换模式不改变画布位置。
- **根据现状整理：**编织卡在较小视口自动折叠，默认展开第一张；卡片可拖动、恢复自动位置、切换方向，手工位置不保存。
- **根据现状整理：**编号标记会避让卡片、其他标记、轮廓线和画布边缘。
- **根据现状整理：**PNG 使用当前显示模式，导出时把编织卡全部展开、扩展画布容纳卡片、填充浅色背景，并以“编织图解-日期时间”命名。
- **待确认：**三种模式的名称、内容和图片导出是否符合用户实际拿去编织的工作方式。

## 五、正确结果

**部分确认：**用户应能看清轮廓、针格、尺寸误差和编织步骤之间的对应关系；导出结果应完整、易读且不改变编辑状态。

**待确认：**正式图解是否需要行号、针号、图例、分页、打印尺寸、矢量格式或结构化逐行文件；当前 PNG 只是一张当前视图图片。

## 六、输入与输出

- 用户输入：当前工具、显示模式、缩放、平移、卡片展开/位置、方向切换和导出操作。
- 系统读取：画布尺寸、轮廓、针格、尺寸标签、编织卡和视口大小。
- 系统生成：屏幕视图、自动布局标注、连接线、编号以及 PNG 文件。
- 方向切换传给[编织方向与加减针方案](./编织方向与加减针方案.md)；导出不修改业务数据。

## 七、数据保存与更新

- 显示模式随方案保存；参数栏展开状态单独保存在当前浏览器。
- 缩放、平移、当前工具、卡片展开状态和手工卡片位置不保存，也不进入撤销历史。
- 画布尺寸变化或侧栏开合后会重新适应或限制视口。
- 轮廓、针格、尺寸或编织规则变化后，显示内容和标注实时更新。
- 图片导出临时改变导出画布尺寸、缩放和位置，完成或失败后恢复屏幕状态。

## 八、编织与计算规则

- 本功能不定义密度、取整、针格或加减针算法，只展示其结果；分别引用[编织密度与画布尺寸](./编织密度与画布尺寸.md)、[尺寸换算与取整确认](./尺寸换算与取整确认.md)、[针格图解生成](./针格图解生成.md)和[编织方向与加减针方案](./编织方向与加减针方案.md)。
- 导出布局当前以扩展标注后所需高度决定画布大小，并对特别高的输出降低位图密度以控制尺寸。
- 产品风险：视觉避让成功不代表标注所述编织规则正确；高密度网格在缩小后可能不可读；PNG 也没有实际打印比例保证。

## 十、不同设备的操作方式

- 鼠标：拖动画布或图形；组合键滚轮缩放；点击模式、缩放、卡片和导出按钮。
- 触控：单指在画布上始终平移，双指缩放和平移；卡片控件可点按和拖动。针格轮廓选择因触控点击被忽略而不可用。
- Apple Pencil：理论上可使用选择、绘制、图形拖动和卡片控件；真实设备未验证。
- iPad 横屏：1024×768 无整页横向溢出；侧栏宽 250 像素，工具栏宽度不足时横向滚动，后部控件不一定立即可见。
- iPad 竖屏：768×1024 仍使用左右栏；工作区约 518 像素宽，工具栏内容约 1,022 像素宽，需要明显横向滚动。
- 风险：缩放按钮约 27×28 像素、画布手柄和部分卡片控制较小，不一定满足舒适触控目标。

## 十一、异常与边界情况

- 画布很大或视口很小时，适应比例不会低于内部值 5，内容可能不能一次完整放入。
- 平移被限制以保持画布和两侧标注区域可触达，但狭窄竖屏可能仍拥挤。
- 多张高卡片可能超出屏幕高度；自动布局会尝试移动，较小视口则折叠。
- 导出画布上下文创建失败时不下载，屏幕状态仍应恢复；页面没有错误提示。
- PNG 下载可能被浏览器策略阻止，页面没有成功/失败状态。
- 切换到针格模式会清除之前选中的段。
- 工具栏横向滚动没有文字提示，用户可能发现不了后部按钮。

## 十二、必须保持不变的行为

- **根据现状整理：**三种模式使用同一画布位置和缩放基准。
- **根据现状整理：**图片导出不永久修改屏幕视口或业务数据。
- **根据现状整理：**标记避让后仍用连接线保留真实针位锚点。
- **根据现状整理：**所有关键工具有可见按钮，不以快捷键作为唯一入口；节点级操作例外已记录为风险。
- 模式名称和具体内容尚未确认，不应被视为不可调整的产品标准。

## 十三、验收标准

- [ ] 三种模式显示的层次和卡片符合本文现状且切换不跳动画布。
- [ ] 鼠标、触控和 Pencil 的平移缩放不会误改轮廓。
- [ ] 选择、取消选择、移动图形和移动视口的手势意图清楚。
- [ ] 标注在常见和密集场景中可读、可追溯到正确边界。
- [ ] PNG 包含当前模式所需内容、完整标注和背景，导出后恢复编辑视图。
- [ ] 1024×768 与 768×1024 下全部工具可触达，不产生整页横向溢出。
- [ ] 真实 iPad 上双指缩放、Pencil 和手掌组合操作无冲突。
- [ ] 浏览器控制台在查看和导出过程中无错误。

## 十四、待确认问题

1. “绘版、针格、量衣”三个名称是否符合用户语言，各模式应该同时显示哪些层？影响理解和导出。
2. 平移工具究竟应只移动画布，还是像当前一样拖图形时移动图形？影响误操作风险。
3. 缩放百分比的 100% 应代表什么？影响用户对尺寸和打印比例的理解。
4. 正式输出需要 PNG、打印 PDF、矢量图、逐行表格还是可机器读取文件？影响导出功能范围。
5. 导出应包含当前模式、固定标准图层，还是让用户勾选内容？影响图解用途。
6. 卡片手工位置是否应随方案保存？影响用户整理复杂图解后的工作保留。
7. iPad 竖屏是否接受横向滚动工具栏和固定侧栏，还是需要独立移动布局？影响完整触控路径。
