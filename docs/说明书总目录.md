> 本目录是产品说明书的唯一总入口。已有确认记录以产品决策记录为准；仍标为“根据现状整理”的行为不因此自动确认，不能把“代码现在如此”理解为“产品必须如此”。

## 一、推荐阅读顺序

1. 先读[产品总览](./产品总览.md)，理解最终目标、用户流程、核心数据和全局原则。
2. 再按本页功能目录进入本次需求涉及的功能说明。
3. 修改前查看[回归验收清单](./回归验收清单.md)中的对应项目和关联功能。
4. 需要判断某条规则是否经过确认时，查看[产品决策记录](./产品决策记录.md)。
5. 遇到产品意图不明时，先看本页“高优先级待确认问题”，再进入功能文档的“待确认问题”。
6. 本次逐项落实已确认规则的范围、依赖、影响和进度见[已确认规则实施清单](./已确认规则实施清单.md)，用户已确认开始，按项开发并记录验收。
7. 专项未决规则见[缝合补偿实施提案](./缝合补偿实施提案.md)和[袖山联动实施提案](./袖山联动实施提案.md)，均待用户确认，不能按总范围授权跳过专项确认。

## 二、文档状态定义

| 状态 | 含义 |
|---|---|
| 已确认 | 用户已经明确确认该产品行为，并能找到可靠依据 |
| 部分确认 | 目标或部分规则已经确认，仍有会影响结果的待确认内容 |
| 根据现状整理 | 只能从当前代码、页面、测试或既有说明观察得出 |
| 待确认 | 无法确定产品意图，不应自行决定 |
| 待整理 | 尚未完成分析 |

状态描述的是产品规则的确认程度，不代表功能是否已经写完，也不代表当前实现正确。

## 四、功能之间的主要关联

1. 用户输入的小样和画布尺寸先形成编织密度与画布针格规模。
2. 用户绘制或导入的轮廓以厘米保存；轮廓尺寸结合密度生成针数、行数候选。
3. 非整数尺寸默认采用厘米误差最小的最近整数，用户可覆盖取整方向；最终结果会改变用于针格化的织片整体宽高。
4. 轮廓、密度、取整选择、固定的针格中心离散规则和编织方向共同决定针格与逐行加减针说明。
5. 明确标记的袖片可关联前、后片袖窿，由袖窿长度和袖片尺寸约束生成袖山轮廓，再进入针格与逐行计算。
6. 画布显示、编织标注和图片导出读取上述计算结果。
7. 方案库保存源数据和部分界面状态；重新打开后再计算针格和指令。

详细的数据关系只在[产品总览](./产品总览.md#七核心数据及其关系)维护。

## 五、高风险影响关系

| 上游变化 | 需要同步重算或复核 | 主要风险 |
|---|---|---|
| 小样针数、行数或小样厘米尺寸 | 画布针格、所有尺寸换算、所有针格、所有加减针说明 | 一个输入会改变全方案；产品直接使用用户提供的密度，不展示或验证测量条件与缩水风险 |
| 画布尺寸 | 网格范围、越界校验、适应视图、导出布局 | 画布总针数和总行数自动四舍五入；缩小画布导致闭合织片越界时保留源轮廓，但停止该织片计算和正式导出 |
| 轮廓节点、控制柄、位置或整体尺寸 | 分段尺寸、针格、起针数、总行数、领口/分片识别、加减针 | 几何微调可能跨过针格边界并改变多行结果 |
| 横向或纵向取整选择 | 织片整体实际宽高、固定边、针格、编织说明 | 当前每片织片只对整体总宽和总高分别提供一次覆盖；局部边界段只显示实际结果和误差，未来明确部位约束另行设计 |
| 针格中心离散 | 各行针段和所有加减针 | 已实现固定针格中心及旧策略迁移，旧结果可能变化；自动重算且提示一次 |
| 编织方向 | 取整后的纵向固定边、行号顺序、加减针方向和标注 | 已确认当前固定自下而上并固定底边；已移除方向切换，旧方案方向归一 |
| 多个闭合图形重叠或分离 | 总画布针格并集、每对象独立计划 | 已确认当前始终作为独立织片，不提供组合；总并集只能用于展示，重叠或相接也不能合并业务结果 |
| 前片或后片袖窿、袖片参数或关联关系 | 自动袖山轮廓、匹配误差、针格和逐行减针计划 | 多对象联动可能使旧袖山失效；默认参数、容差和用户编辑后的重生成策略仍待确认 |

## 六、已发现的现状矛盾

- README 和底层测试仍支持开放路径生成一针格宽轨迹，与已确认的“开放路径不参与针格和编织结果”不一致；编辑器当前排除开放路径的方向正确，底层、测试和正式导出仍需统一，详见[针格图解生成](./功能说明/针格图解生成.md)。
- README 声称存在“分离区域警告”，状态层也会识别分离区域，但当前页面没有展示该警告。详见[编织方向与加减针方案](./功能说明/编织方向与加减针方案.md#十一异常与边界情况)。
- 已完成触控与笔的内容路径及节点按钮，鼠标浏览器路径通过；真实多指、Apple Pencil 和手掌防误触仍须设备验收。详见[形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md#十不同设备的操作方式)。
