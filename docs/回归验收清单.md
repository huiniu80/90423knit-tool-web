# 全局回归验收清单

> 使用方法：每次改动前勾选受影响章节，改动后执行对应项目。标有“真实设备”的项目不能用桌面浏览器模拟结果替代。

## 一、主要用户流程

- [ ] 新用户打开页面后看到一份空白方案、默认小样和画布尺寸，并可开始绘制路径。
- [ ] 用户可完成“设置密度 → 绘制闭合轮廓 → 确认取整 → 查看针格 → 查看加减针 → 导出图片”的完整流程。
- [ ] 用户修改任一上游输入后，相关尺寸、针格、起针数、总行数和加减针标注同步更新。
- [ ] 用户可保存当前方案、切换方案并恢复源数据，详见[方案保存与文件交换](./功能说明/方案保存与文件交换.md)。

## 二、编织密度与画布尺寸

- [ ] 默认小样 10 针、10 行、10 厘米宽、6 厘米高，显示单针 1.00 厘米、单行 0.60 厘米。
- [ ] 默认画布 60×70 厘米显示为 60 针×117 行、共 7,020 个针格。
- [ ] 小样针数和行数拒绝非整数、零、负数以及大于 5,000 的值。
- [ ] 小样厘米尺寸接受 0.1～300，画布厘米尺寸接受 1～300；越界输入不覆盖当前有效值。
- [ ] 超过 2,000 针、3,000 行或 2,000,000 针格时暂停图解生成，并保留原方案数据。
- [ ] 超过 500,000 针格或密度超出当前常见范围时给出警告但允许继续。
- [ ] 处于旧的超限方案时，用户可分步把参数修回安全范围。

详见[编织密度与画布尺寸](./功能说明/编织密度与画布尺寸.md)。

## 三、形状绘制、选择和编辑

- [ ] 路径工具按 0.5 厘米落点，并在接近水平或垂直时显示吸附结果。
- [ ] 至少两个点可通过页面按钮完成开放路径；至少三个点可点击起点闭合。
- [ ] 新路径端点接近已有开放路径端点时准确连接；形成环时转成闭合路径。
- [ ] 选择图形后可编辑名称、位置、宽度和高度，且厘米数据随修改更新。
- [ ] 选择工具可拖动节点、控制柄和边中点；拖动结束后形成一个撤销步骤。
- [ ] 双击轮廓可插入节点且不改变原曲线形状；删除节点不低于开放路径两个、闭合路径三个的下限。
- [ ] 自由模式只改动目标侧；左右镜像模式同步另一侧，并可明确选择以左侧或右侧为准。
- [ ] “整理尺寸”对齐 0.5 厘米并拉直接近水平或垂直的直边，同时保持控制柄相对位置。
- [ ] 打开闭合路径后不再参与织片总针格和加减针；再次闭合后恢复计算。
- [ ] 取消选择和重新选择后，正确显示对应图形属性与编织计划。

详见[形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md)。

## 四、尺寸换算与取整

- [ ] 整数针数或行数直接显示“精确整数”，不要求选择。
- [ ] 非整数结果同时显示向下、向上两个候选的针行数、实际厘米和厘米偏差。
- [ ] 选择横向或纵向取整后，同一织片对应轴向的所有尺寸标签、整体针格和编织计划同步更新。
- [ ] 自下而上取整保持织片底边，自上而下取整保持织片顶边；横向调整保持中心位置。
- [ ] 直线纵向跨度不足半行时不生成纵向尺寸；达到半行或曲线有纵向跨度时保留。
- [ ] 修改密度或轮廓后，已保存的取整方向继续应用并重新计算候选值。

详见[尺寸换算与取整确认](./功能说明/尺寸换算与取整确认.md)。

## 五、针格图解生成

- [ ] “针格中心”“完全在轮廓内”“轮廓有覆盖”三种策略切换后针格按当前定义变化。
- [ ] 每行扫描位置位于该行的垂直中心。
- [ ] 超出画布的针格被裁剪，不在边缘产生额外涂抹。
- [ ] 重叠闭合图形的总针格取并集，不重复计数。
- [ ] 单个图形仍保留独立针格和独立计划，不被其他图形覆盖。
- [ ] 凹形或领口产生的同一行两个针段被保留；三段以上不会被误报为可归纳方案。
- [ ] 修改一个图形不会改变其他未修改图形的独立结果。
- [ ] 开放路径当前是否显示轨迹按待确认决定验收；在决定前必须同时核对 README、底层测试和页面现状矛盾。

详见[针格图解生成](./功能说明/针格图解生成.md)。

## 六、编织方向与加减针方案

- [ ] 每个闭合轮廓拥有独立编织方向，新对象当前默认自下而上。
- [ ] 切换方向后物理行顺序、行号、加减针正负含义和标注同步反转。
- [ ] 第一有效行正确显示起针；织片前后的空画布行不计入计划。
- [ ] 单针段相邻行分别计算左边界和右边界变化，不合并两侧针数。
- [ ] 一段变两段时识别中间收针和左右肩分开；两段变一段时识别中间加起并连接。
- [ ] 同间隔、同针数、同操作的连续变化被压缩为“每几行加/减几针×几次”，阶段顺序不改变。
- [ ] 外侧一次减多针当前显示为“平收”，其编织合理性在用户确认前保持风险标记。
- [ ] 左右镜像轮廓只展示一侧规则并提示另一侧镜像。
- [ ] 三段以上、没有落入针格、开放路径和平织边界分别给出明确状态，不误称为可执行方案。

详见[编织方向与加减针方案](./功能说明/编织方向与加减针方案.md)。

## 七、画布浏览、显示和图片导出

- [ ] 选择、平移和路径工具都有可见选中状态。
- [ ] 选择工具点击画布空白取消选择并可拖动画布；平移工具拖动画布，拖动图形时移动图形。
- [ ] 加减号、适应按钮、组合键滚轮和双指手势在各自设备路径下改变缩放或视口。
- [ ] “绘版”显示轮廓及全部分段编织卡；“针格”显示针格并在点选轮廓段后显示对应卡；“量衣”显示尺寸换算卡。
- [ ] 编织卡可展开、拖动、恢复自动位置和切换方向；密集标记不遮挡轮廓或互相重叠。
- [ ] 切换显示模式时画布位置不因标注留白不同而跳动。
- [ ] PNG 导出使用当前显示模式、浅色背景、时间戳文件名，并完整容纳展开后的标注。
- [ ] 导出后屏幕画布的尺寸、缩放和位置恢复到导出前状态。

详见[画布查看与图片导出](./功能说明/画布查看与图片导出.md)。

## 八、撤销与恢复

- [ ] 新建、删除、移动、缩放、节点编辑、参数、离散策略、方向和取整均可按步骤撤销与重做。
- [ ] 连续拖动只形成一个历史步骤；实时拖动期间不反复自动保存。
- [ ] 路径绘制可逐点撤销和重做；取消草稿后不再从历史恢复该草稿。
- [ ] 撤销后进行新编辑会清空重做分支。
- [ ] 历史最多保留最近 100 个步骤。
- [ ] 新建、切换、替换或导入方案后清空上一方案历史，不跨方案撤销。
- [ ] 工具栏撤销、重做和删除按钮提供触控入口；节点级删除仍需按待确认的触控方案验收。

详见[撤销与恢复](./功能说明/撤销与恢复.md)。

## 九、保存、恢复、导入和导出方案

- [ ] 内容修改约 300 毫秒后自动保存，离开页面时立即补写。
- [ ] 刷新后恢复密度、画布、轮廓、方向、取整、离散策略、显示模式和有效选择。
- [ ] 刷新后不恢复未完成草稿、缩放、平移和当前工具；默认重新进入路径工具。
- [ ] 方案库最多五份；满额时新建或导入要求选择替换目标并二次确认。
- [ ] 不允许删除最后一份方案；删除当前方案后打开最近更新的剩余方案。
- [ ] 重命名不接受空名称，导入同名方案生成不冲突名称。
- [ ] 导出的方案文件不携带本地项目编号，导入后创建独立方案并完整保留编辑源数据。
- [ ] 损坏、普通非方案、未知版本、数据引用不一致或网格超限文件被拒绝且不改动原方案。
- [ ] 本地存储失败时显示错误，不把未成功保存的替换或导入当成成功。
- [ ] 旧单文档和旧版本文件按现有迁移规则恢复；单个损坏项目不清空整个方案库。

详见[方案保存与文件交换](./功能说明/方案保存与文件交换.md)。

## 十、异常输入与极端边界

- [ ] 空值、非数字、无穷值、零和负数不会进入有效密度或画布数据。
- [ ] 图形完全或部分超出画布时只裁剪结果，不破坏原轮廓源数据。
- [ ] 没有图形、图形未落入针格、纵向断开区域和每行三段以上均有可理解状态。
- [ ] 连续快速拖动、缩放、方向切换和取整不会留下半完成状态或控制台错误。
- [ ] 存储不可用、文件读取失败、导出画布失败时保持现有源数据。

## 十一、设备与布局

### iPad 横屏

- [ ] 在 1024×768 下页面无整页横向溢出，侧栏、画布和工具栏均可操作。
- [ ] 工具栏横向滚动时，后部显示模式、缩放、适应和导出操作可被触达。
- [ ] 参数栏收起和展开后画布重新适应可用空间。

### iPad 竖屏

- [ ] 在 768×1024 下侧栏不会让核心画布小到无法编辑。
- [ ] 工具栏横向滚动有明确可发现性，所有操作可触达。
- [ ] 参数输入、方案库和画布之间切换不造成误滚或内容丢失。

### Apple Pencil（真实设备）

- [ ] 可绘制开放和闭合路径，可选择、移动、缩放和编辑节点与控制柄。
- [ ] 可完成取整、切换方向、展开/拖动标注、撤销、重做、删除和导出。
- [ ] 落笔连续，无断笔；手掌接触不会抢占 Pencil 操作；双指缩放不会误改轮廓。

### 触控（真实设备）

- [ ] 不使用键盘或鼠标即可完成所有核心流程。
- [ ] 单指选择/编辑与单指平移的模式或手势不会冲突。
- [ ] 控件和画布手柄的触控目标足够大，快速连续操作有明确反馈。

### 鼠标与键盘

- [ ] 点击、拖动、双击、组合键滚轮及快捷键均按当前说明工作。
- [ ] 不使用快捷键也能通过页面按钮完成核心操作。

## 十二、工程验证

- [ ] 浏览器访问前，服务以规定命令启动，且 `http://localhost:4173/` 健康检查返回 200。
- [ ] 浏览器控制台没有错误或警告。
- [ ] 自动化测试全部通过。
- [ ] 类型检查通过；当前由项目构建命令中的类型检查步骤执行。
- [ ] 项目构建通过。
- [ ] 浏览器验收没有在仓库生成临时日志或其他文件。
- [ ] Git 提交只包含本次需求相关文件。
