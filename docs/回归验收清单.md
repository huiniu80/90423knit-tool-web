# 全局回归验收清单

> 使用方法：每次改动前勾选受影响章节，改动后执行对应项目。标有“真实设备”的项目不能用桌面浏览器模拟结果替代。

## 一、主要用户流程

- [ ] 新用户打开页面后看到一份空白方案、默认小样和画布尺寸，并可开始绘制路径。
- [ ] 用户可完成“设置密度 → 绘制闭合轮廓 → 确认取整 → 查看针格 → 查看加减针 → 导出图片”的完整流程。
- [ ] 用户修改任一上游输入后，相关尺寸、针格、起针数、总行数和加减针标注同步更新。
- [ ] 修改密度后显示一次短暂、非阻塞的重算提示，不弹确认框、不重复打断连续输入。
- [ ] 用户可保存当前方案、切换方案并恢复源数据，详见[方案保存与文件交换](./功能说明/方案保存与文件交换.md)。

## 二、编织密度与画布尺寸

- [ ] 不填写编织机品牌或型号也能完成基础尺寸、针数和行数换算；未提供机器能力时不宣称已验证机器兼容性。
- [ ] 密度输入直接使用用户提供的小样针数、行数、宽度和高度，不展示或强制确认线材、组织、张力、洗涤定型、测量区域及缩水信息。
- [ ] 当前主体平针单密度能完成全部换算，界面不要求花样或罗纹配置；后续加入多密度后，罗纹、花纹等分区分别使用所选密度且跨区针行数连续可执行。
- [ ] 默认小样 10 针、10 行、10 厘米宽、6 厘米高，显示单针 1.00 厘米、单行 0.60 厘米。
- [ ] 默认画布 60×70 厘米显示为 60 针×117 行、共 7,020 个针格。
- [ ] 画布宽度和高度分别自动四舍五入到最近整数，恰好半针或半行时向上，界面不要求用户选择。
- [ ] 小样针数和行数拒绝非整数、零、负数以及大于 5,000 的值。
- [ ] 小样厘米尺寸接受 0.1～300，画布厘米尺寸接受 1～300；越界输入不覆盖当前有效值。
- [ ] 超过 2,000 针、3,000 行或 2,000,000 针格时暂停图解生成，并保留原方案数据。
- [ ] 有效密度不因固定“常见范围”触发警告；超过 500,000 针格时给出设备性能提醒但允许继续。
- [ ] 处于旧的超限方案时，用户可分步把参数修回安全范围。

详见[编织密度与画布尺寸](./功能说明/编织密度与画布尺寸.md)。

## 三、形状绘制、选择和编辑

- [ ] 路径工具按 0.5 厘米落点，并在接近水平或垂直时显示吸附结果。
- [ ] 至少两个点可通过页面按钮完成开放路径；至少三个点可点击起点闭合。
- [ ] 工具栏只提供路径新建入口，不显示通用矩形、圆形、三角形、椭圆或多边形按钮；旧方案和导入文件中的这些图形仍可打开和编辑。
- [ ] 新路径端点接近已有开放路径端点时准确连接；形成环时转成闭合路径。
- [ ] 选择图形后可编辑名称、位置、宽度和高度，且厘米数据随修改更新。
- [ ] 选择工具可拖动节点、控制柄和边中点；拖动结束后形成一个撤销步骤。
- [ ] 点选轮廓边后可通过至少 44×44 像素的可见按钮插入节点，点选节点后可通过同等按钮删除；双击和 Delete 仅作为快捷方式，插点保持曲线形状，删除不低于开放路径两个、闭合路径三个的下限。
- [ ] 默认最近整数和整体覆盖读取同一结果，局部尺寸卡不出现取整按钮；中心恰好在左右或上下边界时，整数整体尺寸不得多算一针或一行。
- [ ] 第二根手指加入、pointercancel 或意外失去指针捕获时，恢复拖动前轮廓，不增加历史且不保存中间位置；双指剩余单指抬起前不得重新编辑，Pencil 不被触控抢占。
- [ ] 自由模式只改动目标侧；左右镜像模式同步另一侧，并可明确选择以左侧或右侧为准。
- [ ] 自相交轮廓保留源数据和编辑能力并显示明确错误；修正前不生成针格、编织方案或正式导出。
- [ ] 尖角轮廓正常参与针格化，不因几何角度本身报错；离散后若消失、断开或形成不支持结构，则显示对应具体状态。
- [ ] 极窄区域形成至少一针时正常计算；完全落不进针格时提示小于当前密度下的一针；中途断开时保留轮廓和针格但停止编织方案。
- [ ] “整理尺寸”对齐 0.5 厘米并拉直接近水平或垂直的直边，同时保持控制柄相对位置。
- [ ] 打开闭合路径后不再参与织片总针格和加减针；再次闭合后恢复计算。
- [ ] 已完成的开放路径可保存、重新打开、继续编辑并与其他开放路径连接；正在绘制且未完成的临时草稿不保存。
- [ ] 取消选择和重新选择后，正确显示对应图形属性与编织计划。
- [ ] 衣片类型和袖窿关联使用明确数据，不仅依赖对象名称猜测；袖片可分别关联前、后袖窿边。
- [ ] 袖肥输入同时显示成衣平铺袖宽和两倍袖围；袖片主体针数按袖围换算，两条袖缝边各加一针且不计入成衣袖围。

详见[形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md)。

## 四、尺寸换算与取整

- [ ] 页面明确区分测量得到的成衣外观尺寸与加入缝合消耗后的织片计算尺寸；针格和加减针使用后者。
- [ ] 侧缝、袖缝和袖窿等常规缝合边为每片增加一针边针；领口、下摆和袖口等开放边不增加，且边针不计入成衣外观尺寸。
- [ ] 平收后手工缝合的肩边为每片默认增加一行，该行不计入成衣外观高度；用户可逐边改为零行。
- [ ] 系统可推荐常规缝合边、肩缝边和开放边；用户可逐边修改，无法可靠判断时必须要求确认而不是静默猜测。
- [ ] 整数针数或行数直接显示“精确整数”，不要求选择。
- [ ] 非整数结果同时显示向下、向上两个候选的针行数、实际厘米和厘米偏差。
- [ ] 向下候选显示实际尺寸减少多少厘米，向上候选显示实际尺寸增加多少厘米；不使用“松量增加”“更贴身”或“更短”等部位相关判断。
- [ ] 正尺寸的整体宽高最低为 1 针、1 行；向下结果为零时不显示零候选，自动采用向上的 1 针或 1 行并提示目标小于当前密度下的一针或一行。
- [ ] 非整数结果默认采用厘米误差最小的最近整数；用户覆盖为向上或向下后，实际尺寸、针格和方案同步更新。
- [ ] 恰好半针或半行时默认向上取整并显示实际正偏差，用户可覆盖为向下。
- [ ] 每片织片只对整体总宽和总高分别提供一次取整覆盖；选择后局部尺寸标签、整体针格和编织计划同步更新，任意边界段不提供独立覆盖按钮。
- [x] 当前自下而上取整保持织片底边，横向调整保持中心位置；不提供自上而下方向。（2026-10-13）
- [ ] 明确启用左右镜像的对象围绕既有中心轴生成对称针格，原始轮廓、图形位置和中心轴不变；非对称对象不自动应用奇偶约束。
- [ ] 普通镜像织片自动使用偶数总针数、中心位于两针之间，整片保持同一奇偶性且左右加减成对；主流程不要求用户选择中心模式。
- [ ] 镜像总宽限定正偶数且最低两针，任意原轴位于两针之间；不同密度每行偶数、左右变化成对，源点、控制柄及轴不动，各片 PNG 使用自己的格原点。
- [ ] 直线纵向跨度不足半行时不生成纵向尺寸；达到半行或曲线有纵向跨度时保留。
- [ ] 通用斜线和曲线尺寸只显示并明确标注横向、纵向跨度，不显示实际边长；袖窿和袖山等明确部位的缝合线长度单独显示。
- [ ] 修改密度或轮廓后，已保存的取整方向继续应用并重新计算候选值，不要求重新确认；显示一次短暂、非阻塞提示，精确整数及最低 1 针、1 行规则优先。

详见[尺寸换算与取整确认](./功能说明/尺寸换算与取整确认.md)。

## 五、针格图解生成

- [x] 当前固定使用针格中心规则；页面不提供“完全在轮廓内”和“轮廓有覆盖”，旧方案中的其他策略不会静默产生不同业务结果。（2026-10-13）
- [x] 旧方案中的“完全在轮廓内”或“轮廓有覆盖”自动迁移为针格中心，原始轮廓不变，并显示一次非阻塞的结果变化提示；不恢复旧规则入口。（2026-10-13 自动化验证；真实设备尚未覆盖。）
- [x] 每行扫描位置位于该行的垂直中心。（2026-10-14 自动化及浏览器样例；真实设备未覆盖。）
- [x] 闭合织片部分或全部超出画布时，保留轮廓并明确提示，但不生成该织片的针格、编织方案或正式导出；扩大画布或完整移回后恢复。（2026-10-14 自动化及浏览器样例；真实设备未覆盖。）
- [ ] 重叠闭合图形的总针格取并集，不重复计数。
- [ ] 当前每个闭合图形始终代表一片独立织片，保留独立针格和独立计划，不被其他图形覆盖；总并集不被误称为单片编织结果。
- [ ] 当前不提供多个轮廓组合功能；相接或重叠轮廓仍分别命名、选择、计算和生成计划。
- [ ] 凹形或领口产生的同一行两个针段被保留；三段以上不会被误报为可归纳方案。
- [x] 修改一个图形不会改变其他未修改图形的独立结果。（2026-10-14 自动化及浏览器样例；真实设备未覆盖。）
- [x] 开放路径闭合前不参与尺寸取整、针格、编织计划或正式导出；底层一格宽轨迹不得进入产品结果。（2026-10-14 自动化及浏览器样例；真实设备未覆盖。）

详见[针格图解生成](./功能说明/针格图解生成.md)。

## 六、编织方向与加减针方案

- [ ] 当前输出明确第几行、左侧或右侧及加针、减针或平收数量，不默认混入手工棒针技法，也不声称具体机器动作已经验证。
- [ ] 每个织片生成可与针格逐行核对的操作表，明确行号、左侧或右侧和加减针数；压缩规律只从逐行表派生，不一致时以逐行表为准。
- [ ] 第 N 行全部操作在编织该行前完成；同一行从左到右展示并同时生效，存在相互影响时明确警告而不自动猜测。
- [ ] 同一行不重叠的左右或中间操作正常输出；同一针被重复占用、操作数量超过针段或作用区域重叠时，显示具体行号和原因，并暂停该织片的有效方案与正式导出。
- [x] 每个闭合轮廓当前均按自下而上生成计划，不提供方向切换。（2026-10-13）
- [ ] 第一有效行正确显示起针；织片前后的空画布行不计入计划。
- [ ] 单针段相邻行分别计算左边界和右边界变化，不合并两侧针数。
- [ ] 一段变两段时显示“本行中间平收 N 针，之后左右两段分别继续编织”，不自动命名领口或肩部；两段变一段时识别中间加起并连接。
- [ ] 同间隔、同针数、同操作的连续变化被压缩为“每几行加/减几针×几次”，阶段顺序不改变。
- [ ] 压缩摘要不为正面行节奏或整齐规律移动操作行；左右同一行、同针数、同工艺时合并为成对表达，不完全一致时分别显示。
- [ ] 当前“外侧一次减超过一针即平收”的旧行为不得被当作正确规则，改造前后均需核对与新工艺分界的差异。
- [ ] 当前不把针数变化提前或延后到相邻行；逐行表严格对应离散针格，最终单侧单行减少一至三针默认减针、四针及以上默认平收，针段完全结束时全部平收，用户可覆盖工艺。
- [ ] 用户可在权威逐行表中按具体行、具体一侧将“减针”与“平收”互相覆盖；针数、行号、位置和针格不变，压缩摘要自动跟随且不提供独立编辑入口。
- [ ] 左右镜像轮廓只展示一侧规则并提示另一侧镜像。
- [x] 三段以上或首末有效行之间出现整行无针时保留轮廓和针格，明确提示“不支持的复杂断开结构”，不生成或导出编织计划；没有落入针格、开放路径和平织边界分别给出明确状态。（2026-10-14 自动化及浏览器样例；真实设备未覆盖。）
- [ ] 自动袖山分别匹配前、后袖窿长度，显示厘米及针行误差，并生成可追溯到袖山针格的逐行平收和减针计划。
- [ ] 第 14 项待确认提案通过后补验吃势分配、手改保留与应用候选、逐侧容差、可行高度区间和离散缝合线估计；当前没有实现，依据[袖山联动实施提案](./袖山联动实施提案.md)。
- [ ] 用户输入实测袖山高度时以其为优先目标；未输入时系统根据袖肥、前后袖窿长度和袖窿深度显示可行范围、推荐值及匹配误差，且允许用户调整。
- [ ] 提供完整袖山轮廓或实测缝合线长度时只显示其与袖窿的现有差值，不重复增加吃势；自动生成且缺少实测长度时吃势默认 0 厘米，并可由用户主动增加。
- [ ] 关联衣片、袖窿轮廓、密度或袖山参数变化后重新校验，旧的失配计划不会继续显示为有效结果。

详见[编织方向与加减针方案](./功能说明/编织方向与加减针方案.md)。

## 七、画布浏览、显示和图片导出

- [ ] 待用户确认后验收：三个模式更名为“编织步骤、针格图、尺寸”；原图层、卡片、PNG 内容及旧方案模式恢复不变，计算源数据和结果不变。依据[更名提案](./功能说明/画布查看与图片导出.md#十四待确认问题)。
- [ ] 待用户确认后验收：1024×768 与 768×1024 下新名称完整、按钮至少 44×44 像素，触控与笔指针点按可切换，其他核心操作可触达；真实 iPad 与 Pencil 验收风险单独说明。

- [x] 第 13 项基础：可触控导出 A4 PDF，针格分块标明针行范围、完整逐行表续页重复表头、覆盖及结束平收与当前表一致；无有效片不下载、无效片列明排除，导出不改视图。（2026-10-16：13 页约 0.98 MB 样例渲染及横竖屏通过；缝合补偿、极端 PDF、真机和打印未覆盖。）

- [ ] 选择、平移和路径工具都有可见选中状态。
- [ ] 选择工具点击画布空白取消选择并可拖动画布；平移工具拖动画布，拖动图形时移动图形。
- [ ] 加减号、适应按钮、组合键滚轮和双指手势在各自设备路径下改变缩放或视口。
- [ ] 100% 缩放明确表示应用内标准查看倍率并标注“仅视图缩放”，不代表屏幕实物比例或打印 1:1，也不改变厘米、针行数和导出计算。
- [ ] “编织步骤”显示轮廓及全部分段编织卡；“针格图”显示针格并在点选轮廓段后显示对应卡；“尺寸”显示尺寸换算卡。
- [ ] 编织卡可展开、拖动和恢复自动位置，不提供方向切换；密集标记不遮挡轮廓或互相重叠。
- [ ] 手工移动后的编织卡按画布相对位置随方案保存；重新打开或切换设备方向后保持可见，未手工移动的卡片继续自动布局。
- [ ] 选择或平移工具下拖动卡片后松开才保存；第二指加入或指针取消恢复原记录，点按恢复自动位置清除记录；排版不占撤销步骤。
- [ ] 方案打开后按桌面和 iPad 横竖屏的可用空间适应完整画布；卡片恢复当前布局默认状态，默认工具选中反馈清楚（绘图为填针法和下针，其他模式为路径），不改变图形厘米位置或计算结果。
- [ ] 300×300 cm 大画布在 768×1024 下可低于 25% 完整适应；同尺寸切换重置临时视图，保存失败不切换。进入竖屏默认关闭抽屉，内侧关闭按钮和遮罩可返回画布，横屏恢复侧栏偏好。
- [ ] 切换显示模式时画布位置不因标注留白不同而跳动。
