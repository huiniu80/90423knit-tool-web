# 缝合补偿实施提案

> 2026-10-15 · **待用户确认**。本提案补全已确认清单第 8 项的几何口径，当前尚未开发。

已经确认：输入的是成衣外观轮廓；常规缝合边每片增加一针，肩边每片默认增加一行且可改零行，开放边不增加。不能把未确认的任意方向外扩方式直接写进代码。

## 建议采用的针格规则

1. 先按原成衣轮廓和密度计算派生针格，再根据已确认的边类型加入边针或补偿行，源厘米轮廓不变。
2. 常规缝合边按每行针段的左端或右端增加一针；斜边和曲线只在实际穿过的行上增加，仍是在该行边缘增加一针，不按曲线法线统一外扩厘米。
3. 肩边按其覆盖的针列增加顶部一行；逐边改零行时该边不加。开放边不增加。
4. 两条常规边在拐角或同一行同一侧交会，只占一个边针；两条肩边覆盖同一列，也只增加一次。肩边与常规边交会采用并集，不把同一格重复计算；实际外角需同时连接新增边针与新增行。
5. 完全水平的常规缝合边没有可定义的逐行左／右边针。本阶段建议标明“不支持水平常规缝合边，请确认边类型”，保留轮廓，暂停该片正式计算；不得擅自改成加一行。用户可按实际用途改成肩边或开放边，其他片继续计算。
6. 补偿后的针格仍必须满足不越界、不中途断开及最多两段等已确认检查；出现冲突明确提示，不裁剪或自动削减补偿。

## 影响和限制

确认后新增逐边类型、确认状态和肩补偿覆盖，进入保存、文件交换及撤销；尺寸区分成衣外观与包含补偿的织片结果，针格与逐行表使用同一最终结果。触控与 Pencil 有逐边选择和确认按钮。

上述方案优先表达实际逐行编织动作，暂不提供任意方向的厘米等距轮廓。水平常规缝合边暂停属于新增边界规则，必须确认。若需要水平常规边也自动计算，需要另行明确其补偿针／行口径，不能由现有“一针”记录推断。

第 9 项可先落实不依赖补偿的整数推荐和全局覆盖；缝合补偿与镜像的联合验收须待第 8 项完成，不把当前结果称为完整可制作方案。
