## 决定二：核心操作必须支持 iPad、Apple Pencil 和触控

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-002 |
| 确认日期 | 待补录；2026-09-02 建档时已写入项目根目录规则 |
| 决定内容 | 绘制、选择、拖动、缩放、编辑、确认和撤销必须可由 Apple Pencil 或触控完成，不能把悬停、右键或键盘快捷键作为唯一入口；横竖屏均需适配 |

| 被排除的其他方案 | 只保证鼠标键盘；把悬停、右键或快捷键作为唯一入口；只适配一种 iPad 方向 |
| 对其他功能的影响 | 控件尺寸、指针事件、手势冲突、触控反馈和验收范围都必须覆盖三类输入 |

| 当前是否仍然有效 | 是；但当前实现尚未完全满足 |

## 决定三：输入轮廓表示成衣外观尺寸，织片另加缝合余量

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-003 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 用户绘制或录入的是测量得到的成衣外观尺寸，不含额外缝合余量；产品需要在此基础上自动加入缝合消耗，得到用于针格和加减针计算的实际织片尺寸 |
| 适用功能 | 轮廓绘制、尺寸换算、针格生成和加减针方案 |
| 决定原因 | 用户明确说明输入来源以及需要产品代为增加缝合余量 |
| 被排除的其他方案 | 把轮廓直接解释为人体净尺寸；把轮廓直接解释为已经包含缝合余量的织片边界 |
| 对其他功能的影响 | 页面需要区分成衣目标尺寸和织片计算尺寸；针格与加减针必须使用加入缝合余量后的尺寸；保存数据需要能够复现这层换算 |
| 对应功能说明文档 | [产品总览](./产品总览.md)、[形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md)、[尺寸换算与取整确认](./功能说明/尺寸换算与取整确认.md) |
| 当前是否仍然有效 | 是；常规缝合边规则已由产品决定-005补充，肩缝等特殊连接仍待确认，当前代码尚未实现 |

## 决定四：主要支持多个独立织片分别片织后缝合

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-004 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 产品的主要制作场景是把后片、左前片、右前片等织片分别片织，完成后再缝合；每个闭合轮廓默认表示一片独立织片 |
| 适用功能 | 多轮廓管理、针格生成、编织计划和缝合余量 |
| 决定原因 | 用户明确说明实际制作采用分片片织，并以多个衣片为例 |
| 被排除的其他方案 | 默认把所有闭合轮廓合并成一片连续织片；默认把整个产品按圈织处理 |
| 对其他功能的影响 | 各织片需要独立的针格、方向、取整、缝合边和编织计划；总画布可叠加展示，但不能把并集当作一片织片的编织依据 |
| 对应功能说明文档 | [产品总览](./产品总览.md)、[针格图解生成](./功能说明/针格图解生成.md)、[编织方向与加减针方案](./功能说明/编织方向与加减针方案.md) |
| 当前是否仍然有效 | 是；是否额外支持圈织、组合织片或用户显式组合仍待确认 |

## 决定五：常规缝合边每片增加一针边针

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-005 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 侧缝、袖缝、袖窿等需要缝合的边，默认在每片织片的对应边增加一针边针；领口、下摆、袖口等开放边不增加 |
| 适用功能 | 轮廓边属性、尺寸换算、针格生成和编织计划 |
| 决定原因 | 用户接受以针数而非固定厘米补偿常规片织缝合消耗的建议 |
| 被排除的其他方案 | 所有边统一增加固定厘米；开放边也统一增加边针；完全不补偿缝合消耗 |
| 对其他功能的影响 | 系统需要识别每条轮廓边是否为缝合边；缝合边的织片计算边界增加一针宽，边针进入起针和逐行针数但不计入成衣外观尺寸 |
| 对应功能说明文档 | [形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md)、[尺寸换算与取整确认](./功能说明/尺寸换算与取整确认.md)、[针格图解生成](./功能说明/针格图解生成.md) |
| 当前是否仍然有效 | 暂定有效；用户后续确认主要使用编织机，该规则需结合实际连接设备复核；肩缝等特殊连接、自动识别和手动覆盖方式待确认，当前代码尚未实现 |

## 决定六：主要面向编织机分片编织

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-006 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 用户主要使用编织机制作毛衣，一般不采用手工棒针编织；产品应优先生成适用于编织机分片编织及后整理连接的方案 |
| 适用功能 | 密度、取整、针格、加减针、编织方向、术语和输出 |
| 决定原因 | 用户明确说明实际制作工具和工作方式 |
| 被排除的其他方案 | 默认以手工棒针技法和手织操作节奏设计全部说明 |
| 对其他功能的影响 | 不应默认推荐三针收针等手织连接；加减针必须考虑编织机针床、机型能力、持针/引返、移针、套口或缝合设备；输出应使用机织用户可执行的表达 |
| 对应功能说明文档 | [产品总览](./产品总览.md)、[编织密度与画布尺寸](./功能说明/编织密度与画布尺寸.md)、[编织方向与加减针方案](./功能说明/编织方向与加减针方案.md) |
| 当前是否仍然有效 | 是；产品决定-007进一步确认机型不参与核心换算，后整理连接设备仍待确认 |

## 决定七：核心形状换算不依赖编织机型号

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-007 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 编织机品牌和型号不是必填信息，不参与成衣轮廓到织片尺寸、针数和行数的基础换算；核心换算使用成衣外观轮廓、实际织物密度和边类型 |
| 适用功能 | 密度、尺寸换算、针格和方案输入 |
| 决定原因 | 用户希望测量成衣后直接交给工具复刻形状，不要求绑定特定编织机 |
| 被排除的其他方案 | 必须先选择编织机型号才能生成基础针格和加减针方案 |
| 对其他功能的影响 | 机器针床宽度和动作能力校验只能作为可选增强；未提供机型时仍应完成核心计算，但不得把机器兼容性描述为已验证 |
| 对应功能说明文档 | [产品总览](./产品总览.md)、[编织密度与画布尺寸](./功能说明/编织密度与画布尺寸.md)、[编织方向与加减针方案](./功能说明/编织方向与加减针方案.md) |
| 当前是否仍然有效 | 是 |

## 尚未形成决定的事项

下列内容没有可靠用户确认，不得补写为决定：

- 小样测量口径、缩率，以及肩缝等特殊连接的余量规则。
- 可选机器能力校验需要覆盖哪些机型、针距和针床配置，以及套口、缝盘或其他连接设备。
- 画布和织片的针行取整规则。
- 三种针格离散策略的业务用途与默认值。
- 开放路径的产品含义。
- 是否需要额外支持圈织，以及是否允许用户把多个轮廓显式组合为一片织片。
- 实际加减针技法、正反面行限制、花样倍数和对称配针。
- PNG、逐行文字、压缩规律或针法图符中哪一种是正式交付物。
