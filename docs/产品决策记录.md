## 决定二：核心操作必须支持 iPad、Apple Pencil 和触控

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-002 |
| 确认日期 | 待补录；2026-09-02 建档时已写入项目根目录规则 |
| 决定内容 | 绘制、选择、拖动、缩放、编辑、确认和撤销必须可由 Apple Pencil 或触控完成，不能把悬停、右键或键盘快捷键作为唯一入口；横竖屏均需适配 |
| 适用功能 | 所有界面和交互功能 |
| 决定原因 | 项目明确面向 iPad 使用场景 |
| 被排除的其他方案 | 只保证鼠标键盘；把悬停、右键或快捷键作为唯一入口；只适配一种 iPad 方向 |
| 对其他功能的影响 | 控件尺寸、指针事件、手势冲突、触控反馈和验收范围都必须覆盖三类输入 |
| 对应功能说明文档 | [形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md)、[画布查看与图片导出](./功能说明/画布查看与图片导出.md)、[撤销与恢复](./功能说明/撤销与恢复.md) |
| 当前是否仍然有效 | 是；但当前实现尚未完全满足 |

## 决定三：输入轮廓表示成衣外观尺寸，织片另加缝合余量

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-003 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 用户绘制或录入的是测量得到的成衣外观尺寸，不含额外缝合余量；产品需要在此基础上自动加入缝合消耗，得到用于针格和加减针计算的实际织片尺寸 |
| 适用功能 | 轮廓绘制、尺寸换算、针格生成和加减针方案 |
| 决定原因 | 用户明确说明输入来源以及需要产品代为增加缝合余量 |
| 被排除的其他方案 | 把轮廓直接解释为人体净尺寸；把轮廓直接解释为已经包含缝合余量的织片边界 |
| 对其他功能的影响 | 页面需要区分成衣目标尺寸和织片计算尺寸；针格与加减针必须使用加入缝合余量后的尺寸；保存数据需要能够复现这层换算 |
| 对应功能说明文档 | [产品总览](./产品总览.md)、[形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md)、[尺寸换算与取整确认](./功能说明/尺寸换算与取整确认.md) |
| 当前是否仍然有效 | 是；具体缝合方式、各边余量和换算规则待确认，当前代码尚未实现 |

## 尚未形成决定的事项

下列内容没有可靠用户确认，不得补写为决定：

- 小样测量口径、缩率，以及不同缝合方式对应的余量规则。
- 画布和织片的针行取整规则。
- 三种针格离散策略的业务用途与默认值。
- 开放路径的产品含义。
- 多图形是独立织片还是组合织片。
- 实际加减针技法、正反面行限制、花样倍数和对称配针。
- PNG、逐行文字、压缩规律或针法图符中哪一种是正式交付物。

确认后请按上述表格新增决定，不要改写历史决定；被替代的决定保留并把“当前是否仍然有效”改为否，同时链接新决定。
