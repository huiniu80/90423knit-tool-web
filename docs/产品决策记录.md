## 决定三：输入轮廓表示成衣外观尺寸，织片另加缝合余量

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-003 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 用户绘制或录入的是测量得到的成衣外观尺寸，不含额外缝合余量；产品需要在此基础上自动加入缝合消耗，得到用于针格和加减针计算的实际织片尺寸 |
| 适用功能 | 轮廓绘制、尺寸换算、针格生成和加减针方案 |
| 决定原因 | 用户明确说明输入来源以及需要产品代为增加缝合余量 |
| 被排除的其他方案 | 把轮廓直接解释为人体净尺寸；把轮廓直接解释为已经包含缝合余量的织片边界 |
| 对其他功能的影响 | 页面需要区分成衣目标尺寸和织片计算尺寸；针格与加减针必须使用加入缝合余量后的尺寸；保存数据需要能够复现这层换算 |
| 对应功能说明文档 | [产品总览](./产品总览.md)、[形状绘制与轮廓编辑](./功能说明/形状绘制与轮廓编辑.md)、[尺寸换算与取整确认](./功能说明/尺寸换算与取整确认.md) |
| 当前是否仍然有效 | 是；常规缝合边规则已由产品决定-005补充，平收后手工缝合的肩缝规则及边类型指定方式已由产品决定-017补充，当前代码尚未实现 |

| 确认日期 | 2026-09-07 |
| 决定内容 | 产品的主要制作场景是把后片、左前片、右前片等织片分别片织，完成后再缝合；每个闭合轮廓默认表示一片独立织片 |

## 决定五：常规缝合边每片增加一针边针

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-005 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 侧缝、袖缝、袖窿等需要缝合的边，默认在每片织片的对应边增加一针边针；领口、下摆、袖口等开放边不增加 |
| 适用功能 | 轮廓边属性、尺寸换算、针格生成和编织计划 |

| 当前是否仍然有效 | 是；产品决定-017补充平收后手工缝合的肩缝规则，以及系统推荐、用户逐边修改和无法判断时确认的边类型流程；当前代码尚未实现 |

## 决定八：使用完成同等后整理的小样密度

|---|---|

| 确认日期 | 2026-09-07 |

| 对其他功能的影响 | 最近整数算法需要明确半值规则；界面应显示向上推荐、实际厘米和正偏差，并保留向下覆盖入口 |

## 决定十三：普通镜像织片自动采用偶数针中心模式

| 项目 | 内容 |
|---|---|
| 决定编号 | 产品决定-013 |
| 确认日期 | 2026-09-07 |
| 决定内容 | 为保证系统稳定、可靠、简单，普通左右镜像织片自动采用偶数总针数，中心轴位于两针之间；整个织片保持同一奇偶性，左右加减针成对进行，主流程不要求用户选择中心模式 |
| 适用功能 | 左右镜像、尺寸取整、针格生成和加减针方案 |
| 决定原因 | 用户明确要求系统稳定可靠、简单方便，并将具体技术选择交由产品规则处理 |
| 被排除的其他方案 | 按全片累计误差自动在奇偶模式之间切换；每个织片都要求用户先理解并选择中心模式；逐行改变奇偶性 |
